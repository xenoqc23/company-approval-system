사내결재시스템 — 다른 Windows PC로 복사해서 시연하기

기존 PC에서

1. 프로그램을 실행한 검은색 창에서 Ctrl+C를 눌러 종료합니다.
2. setup.bat, run.bat, launcher.py, manage.py, workflow가 들어 있는 프로그램 폴더를 찾습니다.
3. 그 폴더를 USB 등에 복사합니다. 기존 기안과 계정을 쓰려면 var 폴더도 함께 복사합니다.
4. 복사한 폴더 안의 .venv 폴더만 삭제합니다. 원래 PC의 폴더는 그대로 둡니다.
   .venv는 PC마다 다시 설치하는 실행 환경입니다. var는 계정·기안 데이터이므로 유지합니다.

시연할 새 PC에서

1. Python 3.10 이상이 설치되어 있으면 다음 단계로 넘어갑니다.
   없다면 https://www.python.org/downloads/windows/ 에서 Python을 설치합니다.
   Add python.exe to PATH가 보이면 체크합니다.
2. 복사한 프로그램 폴더를 본인 계정의 다운로드 폴더 등 일반 폴더에 넣습니다.
   USB 안이나 압축 파일 안에서 바로 실행하지 말고 새 PC로 복사한 뒤 실행합니다.
3. setup.bat을 더블클릭합니다. 필요한 프로그램을 설치하므로 처음에는 인터넷 연결이 필요합니다.
   새 PC용 .venv를 만들고, 기존 DB를 백업한 뒤 필요한 업데이트를 적용합니다.
   var에 기존 계정이 있으면 초기 비밀번호 입력 없이 기존 계정과 기안을 그대로 유지합니다.
4. 설치가 완료되면 run.bat을 더블클릭합니다. 브라우저가 자동으로 열립니다.
5. 기존에 사용하던 아이디와 비밀번호로 로그인합니다. 관리자 비밀번호를 바꿨다면 바뀐 값을 사용합니다.
6. 시연하는 동안 검은색 실행 창을 열어둡니다. 종료할 때는 Ctrl+C를 누릅니다.

기존 데이터를 가져오지 않고 새 예시로 시연하려면

  새 PC에서 아래 최신 ZIP을 내려받아 압축을 풀고 setup.bat을 실행합니다.
  https://github.com/xenoqc23/company-approval-system/archive/refs/heads/prototype/pc-demo-20261008.zip
  처음 설치할 때 입력한 초기 비밀번호로 예시 직원 계정에 로그인합니다.
  admin은 처음 로그인할 때 비밀번호 변경이 필요합니다.

복사 이후의 데이터

  두 PC는 각자의 var 폴더를 사용합니다. 새 PC에서 작성한 기안은 원래 PC에 자동으로 반영되지 않습니다.

오류가 나면

  No module named pip / 실행 환경을 찾을 수 없음
    복사한 새 PC의 프로그램 폴더에서 .venv만 삭제한 뒤 setup.bat을 다시 실행합니다.
    var 폴더는 유지합니다.

  액세스가 거부되었습니다 / WinError 5
    회사의 안전 폴더나 OneDrive 대신 본인 계정의 일반 폴더로 옮겨 실행합니다.
    마지막 오류 문구를 확인하고, 해결되지 않으면 오류 화면을 전달합니다.

  Python was not found
    Python 설치를 확인하고 setup.bat을 다시 실행합니다.

  설치가 끝나지 않음
    마지막 오류 내용을 확인합니다. 설치 완료 메시지가 나오기 전에는 run.bat으로 넘어가지 않습니다.
