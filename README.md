# Xenosys 사내결재시스템 — 설치 없는 Windows 시안

Windows 64비트용입니다. ZIP을 모두 풀고 `CompanyApproval.exe`를 실행합니다. 시스템 Python 설치와 setup.bat 실행은 필요 없습니다.

기존 프로그램을 종료하고, 기존 `var` 폴더를 새 EXE 옆에 복사한 후 실행하면 계정·기안·연차를 유지합니다. 업데이트 전 DB를 자동 백업합니다.

2026-10-14: 직원 일정·공휴일·공용연차, 입사일 기준 새 연도 총연차, 인원별 현황표와 Excel, 장기근속 포상·경조사 안내, Xenosys 화면 구성.

경리 계정에서 직원별 연차 관리 → 입사일·연차 관리를 이용하세요. 자세한 실행 및 업데이트 방법은 [START_WITHOUT_PYTHON.txt](START_WITHOUT_PYTHON.txt)에 있습니다.

패키지에는 실제 계정·문서 DB를 포함하지 않습니다. 새 DB에는 가상 직원의 예시만 생성합니다.
