사내결재시스템 PC 시안 — 처음 실행하는 분을 위한 안내

이 시안은 본인 PC에서 화면과 업무 흐름을 확인하는 프로그램입니다.
NAS/MariaDB는 연결하지 않습니다. PC 폴더 안에 별도 테스트 DB를 만듭니다.

이미 실행 중인 이전 버전을 업데이트할 때는 UPDATE_WINDOWS.txt를 먼저 확인합니다.
기존 프로그램 폴더의 .venv와 var를 보관한 채 최신 파일을 덮어씁니다.

1. Python 설치 (처음 한 번)

  https://www.python.org/downloads/windows/ 에서 Python 3.14의
  Windows installer (64-bit)를 받아 설치합니다.
  설치창에 Add python.exe to PATH가 보이면 체크한 뒤 Install Now를 선택합니다.
  이미 Python 3.10 이상이 설치되어 있으면 이 단계는 생략할 수 있습니다.

2. 프로그램 ZIP 압축 풀기

  company-approval-prototype.zip을 다운로드합니다.
  파일을 마우스 오른쪽 버튼으로 클릭해 '모두 압축 풀기'를 선택합니다.
  압축을 푼 뒤 company-approval-prototype 폴더를 엽니다.
  setup.bat, run.bat, manage.py가 보이는 폴더가 맞습니다.
  ZIP 파일 안에서 바로 실행하지 마세요.

3. setup.bat 더블클릭 (처음 한 번)

  검은색 창이 열리며 필요한 프로그램을 설치합니다.
  설치 중에는 인터넷 연결이 필요합니다. 창을 닫지 않고 기다립니다.
  '시안 계정 초기 비밀번호:'가 나오면 사용할 비밀번호를 입력하고 Enter를 누릅니다.
  요청했던 초기 비밀번호를 사용하려면 1234를 입력합니다.
  비밀번호를 입력해도 글자나 별표가 보이지 않는 것이 정상입니다.
  '설치가 완료되었습니다!'가 나오면 아무 키를 눌러 창을 닫습니다.
  이 비밀번호는 아래 가상 직원 계정에 함께 적용됩니다.

4. run.bat 더블클릭 (프로그램을 사용할 때마다)

  검은색 창이 열리고 브라우저가 자동으로 열립니다.
  자동으로 열리지 않으면 본인 PC의 Chrome 또는 Edge 주소창에
  127.0.0.1:8000 을 입력합니다.
  검은색 실행 창은 사용 중에 열어두어야 합니다.

5. 먼저 employee로 로그인해 화면 확인

  아이디: employee
  비밀번호: 설치할 때 입력한 초기 비밀번호

  예시 계정
    employee   일반 직원·기안자
    reviewer   검토자
    approver   최종 승인자
    accounting 경리 담당자
    admin      관리자

  admin은 처음 로그인하면 초기 비밀번호를 새 비밀번호로 변경해야 합니다.
  새 비밀번호는 8자 이상으로, 숫자 이외의 문자도 포함합니다.
  admin의 비밀번호를 바꿔도 다른 예시 직원의 비밀번호는 그대로입니다.

6. 휴가원 결재 순서 직접 확인

  employee 로그인 → 휴가 신청 → 비어 있는 평일 선택 → 사유 입력
  → 검토자 김민준, 최종 승인자 박지훈 선택 → 기안 제출
  → 로그아웃
  → reviewer 로그인 → 결재함 → 해당 문서 → 검토 승인 → 로그아웃
  → approver 로그인 → 결재함 → 해당 문서 → 최종 승인 → 로그아웃
  → employee 로그인 → 잔여 연차와 내 기안 진행상황 확인
  → accounting 로그인 → 최종 승인 문서함에서 문서 확인

  예시 문서가 이미 있으므로 날짜가 중복되면 다른 평일을 선택합니다.
  같은 브라우저에서 한 계정씩 로그아웃하고 다음 계정으로 로그인합니다.

7. 종료 / 다시 실행

  실행 중인 검은색 창에서 Ctrl+C를 누르면 종료됩니다.
  브라우저만 닫으면 프로그램은 계속 실행될 수 있습니다.
  다음에는 run.bat만 다시 더블클릭하면 됩니다.
  기안 데이터는 var 폴더에 남으므로 이 폴더는 삭제하지 마세요.
  프로그램 폴더를 옮기면 기존 실행 환경이 작동하지 않을 수 있습니다.
  그때는 var는 그대로 보관하고 .venv 폴더만 삭제한 뒤 setup.bat을 다시 실행합니다.

자주 만나는 문제

  Python was not found
    Python 설치를 확인하고 setup.bat을 다시 실행합니다.

  설치 중 다운로드 오류
    인터넷 연결을 확인하고 setup.bat을 다시 실행합니다.
    기존 계정이 있으면 예시 데이터는 다시 추가하지 않습니다.

  No module named pip
    앞선 설치가 중단되어 실행 환경에 pip가 빠진 상태입니다.
    최신 setup.bat은 이 상태를 확인하고 pip를 자동으로 복구합니다.
    이미 받은 이전 버전이라면 프로그램 폴더의 .venv 폴더만 삭제하고
    setup.bat을 다시 실행합니다. 기안이 저장된 var 폴더는 보관합니다.

  WinError 5 / 액세스가 거부되었습니다
    프로그램을 본인 계정의 일반 다운로드 폴더에 새로 압축을 풀어 실행합니다.
    회사의 안전 폴더나 OneDrive 폴더에서는 파일 생성/실행이 제한될 수 있습니다.
    이전에 중단된 .venv 실행 환경은 새 폴더에 복사하지 않습니다.
    일반 폴더에서도 같은 오류가 계속되면 정확한 오류 내용을 확인합니다.

  8000번 포트를 이미 사용 중
    이전에 열어둔 실행 창을 종료한 뒤 run.bat을 다시 실행합니다.

  브라우저에서 사이트에 연결할 수 없음
    run.bat의 검은색 창이 켜져 있는지, 오류가 표시되었는지 확인합니다.

  오류가 나고 멈춤
    마지막 오류 문구를 복사하거나 창 전체 화면을 캡처해 전달합니다.
    비밀번호는 전달하지 않습니다.

Mac/Linux

  Python 3.10 이상을 설치하고 압축을 푼 폴더에서 터미널을 엽니다.
  처음 설치: python3 launcher.py setup
  이후 실행: python3 launcher.py run
  초기 비밀번호를 입력하고 브라우저로 확인하는 흐름은 같습니다.

이번 안내는 본인 PC에서 시안을 보는 방법입니다.
전 직원이 NAS로 접속하는 운영 구성은 이후 별도로 연결·검증해야 합니다.
