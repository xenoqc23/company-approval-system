사내결재시스템 — 파이썬 설치 없이 실행하기 (Windows 64비트)

1. 배포 ZIP을 다운로드하고 일반 다운로드 폴더 등에 압축을 모두 풉니다.
2. CompanyApproval.exe, runtime, vendor, workflow가 함께 들어 있는 폴더를 엽니다.
3. CompanyApproval.exe를 더블클릭합니다. setup.bat이나 Python 설치는 필요하지 않습니다.
4. 처음 실행하여 계정이 없으면 초기 비밀번호를 입력하고 Enter를 누릅니다.
   이전에 요청한 초기 비밀번호를 사용하려면 1234를 입력합니다.
   입력한 글자나 별표가 보이지 않는 것이 정상입니다.
5. 브라우저가 자동으로 열리면 employee, reviewer, approver, accounting, admin 중
   시연할 계정으로 로그인합니다. admin은 첫 로그인 시 비밀번호를 변경합니다.
6. 실행 중인 검은색 창은 열어둡니다. 종료할 때는 그 창에서 Ctrl+C를 누릅니다.

기존 계정과 기안을 가져오려면

  원래 프로그램을 Ctrl+C로 종료하고 var 폴더를 복사합니다.
  새 프로그램을 처음 실행하기 전에 CompanyApproval.exe와 같은 위치에 var를 넣습니다.
  기존 아이디와 비밀번호를 그대로 사용합니다. 데이터를 다시 만들거나 초기화하지 않습니다.
  복사 이후 두 PC의 데이터는 자동 동기화되지 않습니다.

보관해야 하는 파일

  CompanyApproval.exe만 따로 옮기지 마세요.
  runtime, vendor, workflow 등 프로그램 폴더 전체를 함께 보관합니다.
  var에는 계정과 기안이 저장되므로 삭제하지 않습니다.
  업데이트할 때도 프로그램을 종료하고 var를 유지합니다.

실행이 안 되면

  ZIP 안에서 직접 실행하지 않고 먼저 압축을 모두 풀었는지 확인합니다.
  회사의 안전 폴더나 OneDrive 대신 본인 계정의 일반 폴더에서 실행합니다.
  이전 프로그램이 켜져 있으면 해당 실행 창에서 Ctrl+C로 종료합니다.
  검은색 창에 나오는 오류 내용을 확인하고, 해결되지 않으면 오류 화면을 전달합니다.

Python 런타임과 필요한 라이브러리는 프로그램 폴더에 포함되어 있습니다.
처음 실행할 때도 별도 패키지 다운로드는 하지 않습니다.
