사내결재시스템 시안 업데이트 방법 (Windows)

1. 프로그램 실행 창에서 Ctrl+C를 눌러 종료합니다.
2. GitHub의 prototype/pc-demo-20261008 브랜치에서 Code → Download ZIP으로 최신 파일을 받습니다.
3. ZIP을 새 폴더에 압축 풉니다. launcher.py, setup.bat, workflow 폴더가 보이는 곳까지 들어갑니다.
4. 그 안의 파일과 폴더를 모두 선택해, 지금 사용 중인 프로그램 폴더에 복사합니다.
5. 같은 이름의 파일을 바꾸겠다고 나오면 '대상 폴더의 파일 덮어쓰기'를 선택합니다.
   기존 프로그램 폴더 전체를 삭제하지 마세요. .venv와 var 폴더를 유지해야 합니다.
6. 기존 프로그램 폴더에서 setup.bat을 실행합니다.
   필요한 프로그램을 확인하고, 기존 DB를 백업한 뒤 업데이트합니다.
   기존 계정이 있으면 초기 비밀번호를 다시 입력하거나 데이터를 초기화하지 않습니다.
7. 완료 후 run.bat을 실행합니다.
8. 브라우저에서 Ctrl+F5를 눌러 새 화면을 불러옵니다.

이번 변경
- 확인 단계는 검토확인·승인확인으로 표시하고 초록색 체크로 강조합니다.
- 본인이 확인한 단계에는 내가 확인함을 표시합니다.
- 검토·승인 확인 성공 시 완료 팝업이 뜨며, 처리 중에는 중복 클릭을 막습니다.
- 검토자·승인자는 admin을 제외한 주임 이상 직원만 지정할 수 있습니다.
- 결재선은 부서를 먼저 선택한 뒤 그 부서의 직원을 선택합니다.
- 경리 최종 승인 문서함은 휴가원·구매요청서·생산 재고 요청으로 나눠 표시합니다.
- 글자는 처음 화면과 확대 화면의 중간 크기로 조정하고 진한 색을 유지했습니다.
- 비밀번호는 숫자만으로도 4자 이상이면 사용할 수 있습니다.
- 내 계정 메뉴에서 본인의 비밀번호를 변경할 수 있습니다.
- 직원·권한 관리를 미분류 계정과 부서별 탭으로 구분했습니다.
- 생산 재고 요청에서 단가, 총가격, 최종 승인자 항목을 없앴습니다.
- 생산 재고는 검토가 끝나면 발주 담당자에게 전달됩니다.
- 왼쪽에 '생산 재고 요청함'을 추가했습니다.
- 발주 담당자는 admin이 '구매·발주 처리' 권한을 부여한 직원입니다.
- 기존 검토 완료 재고 문서는 발주대기로 전환되며 이전 이력은 보관합니다.

프로그램 설치 창에서 오류가 나오면 실행 단계로 넘어가기 전에 오류 화면을 확인하세요.
