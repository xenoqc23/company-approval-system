사내결재시스템 시안 업데이트 방법 (Windows)

1. 프로그램 실행 창에서 Ctrl+C를 눌러 종료합니다.
2. GitHub의 prototype/pc-demo-20261008 브랜치에서 Code → Download ZIP으로 최신 파일을 받습니다.
3. ZIP을 새 폴더에 압축 풉니다. launcher.py, setup.bat, workflow 폴더가 보이는 곳까지 들어갑니다.
4. 그 안의 파일과 폴더를 모두 선택해, 지금 사용 중인 프로그램 폴더에 복사합니다.
5. 같은 이름의 파일을 바꾸겠다고 나오면 '대상 폴더의 파일 덮어쓰기'를 선택합니다.
   기존 프로그램 폴더 전체를 삭제하지 마세요. .venv와 var 폴더를 유지해야 합니다.
6. 기존 프로그램 폴더에서 setup.bat을 실행합니다.
   필요한 프로그램을 확인하고, 기존 DB를 백업한 뒤 업데이트합니다.
   기존 계정이 있으면 초기 비밀번호를 다시 입력하거나 데이터를 초기화하지 않습니다.
7. 완료 후 run.bat을 실행합니다.
8. 브라우저에서 Ctrl+F5를 눌러 새 화면을 불러옵니다.

2026-10-15 최신 변경: NAS 연동 전 전결·규정 관리 구현

- 홈 오른쪽 결재 진행 상태에는 진행 중인 내 기안만 표시합니다. 완료 문서는 목록에서 제외합니다.
- 규정 관리: 전결·연차·경조사비·장기근속 포상 기준을 관리합니다.
- 경리·admin은 전결규정을 수정하고 적용 결과를 미리 볼 수 있습니다.
- 연차·경조사비·장기근속 포상 편집은 연차 관리 권한이 있는 경리 계정에서 사용합니다.
- 초기 규정: 10만원 이하 구매는 기안→승인, 부장 휴가원은 검토 생략입니다.
- 기안자≤검토자≤승인자와 전결 직급 조건을 함께 적용하며 자격이 맞으면 본인 승인도 가능합니다.
- 기존 제출 문서는 결재선을 유지하고, 새 제출 문서부터 현재 규정을 적용합니다.
- 올해 총연차는 직원별 연차 관리→총연차 재계산에서 미리보기 후 선택 적용합니다.
- 기존 총연차는 수동값으로 표시합니다. 새 기준으로 바꿀 직원은 수동값 대체 확인도 선택하세요.
- 기존 사용연차와 승인·취소 이력은 유지합니다. 입사일이 없는 직원은 자동산정 대기입니다.
- 공용연차는 입사일 당일 이후의 휴무만 차감하며 중복 휴가를 안내합니다.

미정 사항
- 10만원 초과~100만원 이하 예시는 사용 안 함 상태이며 경리·admin이 직급 범위 확인 후 사용할 수 있습니다.
- 사용 규정이 없는 구간은 기존 기본 경로를 사용합니다.
- 100만원 초과 전결과 적격 승인자 부재 시 별도 예외는 아직 보류입니다.

직접 확인할 순서는 DEMO_CHECKLIST.txt를 확인하세요.
처음 사용하는 PC라면 START_HERE.txt를 따릅니다.
다른 PC로 옮길 때는 MOVE_TO_OTHER_PC.txt를 확인하세요.
이번 파일은 Python 설치 후 setup.bat/run.bat으로 실행하는 PC 검토본입니다.
NAS/MariaDB는 아직 연결하지 않았습니다.
