사내결재시스템 시안 업데이트 방법 (Windows)

1. 프로그램 실행 창에서 Ctrl+C를 눌러 종료합니다.
2. GitHub의 prototype/pc-demo-20261008 브랜치에서 Code → Download ZIP으로 최신 파일을 받습니다.
3. ZIP을 새 폴더에 압축 풉니다. launcher.py, setup.bat, workflow 폴더가 보이는 곳까지 들어갑니다.
4. 그 안의 파일과 폴더를 모두 선택해, 지금 사용 중인 프로그램 폴더에 복사합니다.
5. 같은 이름의 파일을 바꾸겠다고 나오면 '대상 폴더의 파일 덮어쓰기'를 선택합니다.
   기존 프로그램 폴더 전체를 삭제하지 마세요. .venv와 var 폴더를 유지해야 합니다.
6. 기존 프로그램 폴더에서 setup.bat을 실행합니다.
   필요한 프로그램을 확인하고, 기존 DB를 백업한 뒤 업데이트합니다.
   기존 계정이 있으면 초기 비밀번호를 다시 입력하거나 데이터를 초기화하지 않습니다.
7. 완료 후 run.bat을 실행합니다.
8. 브라우저에서 Ctrl+F5를 눌러 새 화면을 불러옵니다.

2026-10-15 최신 변경: 여러 기안의 결재 진행 상태

- 홈 결재 진행 상태에 '진행 중 N건'과 '확인할 기안 선택' 목록을 추가했습니다.
- 진행 중은 검토대기·최종승인대기 기안 수입니다. 진행 중인 최신 기안을 기본으로 보여줍니다.
- 다른 기안을 선택하면 해당 문서의 결재 단계와 상세보기 링크로 바뀝니다.
- 완료·반려·취소 기안도 선택할 수 있고, 임시저장·삭제·다른 직원의 문서는 제외합니다.
- 최근 문서함의 종류 탭을 바꿔도 선택한 기안을 유지합니다.
- 위의 1~8번 순서로 업데이트하세요. var와 .venv 폴더는 보관합니다.

이전 변경: H · 민트 플로우

- 선택한 시안을 바탕으로 홈과 전체 공통 디자인을 민트·초록·흰색으로 변경했습니다.
- 왼쪽 문구: 함께하는 업무, 더 가벼운 하루.
- 홈: 나의 연차 현황, 휴가/구매/생산 재고 빠른 신청, 종류별 최근 문서, 결재 진행 상태.
- 회사 로고, 개인 연차 수치, 결재·알림·일정·연차 관리·엑셀·관리자 권한 기능을 유지합니다.
- 구매/재고 작성 시 불필요한 빈 열, 작은 PC 화면에서 하단 메뉴가 가려지는 현상을 보완했습니다.
- 글꼴과 일러스트는 파일에 포함되어 별도로 설치할 필요가 없습니다.
- 이번 디자인은 setup.bat 설치 후 run.bat으로 실행합니다. EXE를 만들 필요는 없습니다.

처음 사용하는 PC라면 START_HERE.txt를 따릅니다.
다른 PC로 옮길 때는 MOVE_TO_OTHER_PC.txt를 확인하세요.
기존 계정과 문서는 var 폴더에 있으므로 삭제하지 마세요.
설치 오류가 나오면 실행 단계로 넘어가기 전에 오류 화면을 확인하세요.
