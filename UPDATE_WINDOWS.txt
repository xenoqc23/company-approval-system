사내결재시스템 시안 업데이트 방법 (Windows)

1. 프로그램 실행 창에서 Ctrl+C를 눌러 종료합니다.
2. GitHub의 prototype/pc-demo-20261008 브랜치에서 Code → Download ZIP으로 최신 파일을 받습니다.
3. ZIP을 새 폴더에 압축 풉니다. launcher.py, setup.bat, workflow 폴더가 보이는 곳까지 들어갑니다.
4. 그 안의 파일과 폴더를 모두 선택해, 지금 사용 중인 프로그램 폴더에 복사합니다.
5. 같은 이름의 파일을 바꾸겠다고 나오면 '대상 폴더의 파일 덮어쓰기'를 선택합니다.
   기존 프로그램 폴더 전체를 삭제하지 마세요. .venv와 var 폴더를 유지해야 합니다.
6. 기존 프로그램 폴더에서 setup.bat을 실행합니다.
   필요한 프로그램을 확인하고, 기존 DB를 백업한 뒤 업데이트합니다.
   기존 계정이 있으면 초기 비밀번호를 다시 입력하거나 데이터를 초기화하지 않습니다.
7. 완료 후 run.bat을 실행합니다.
8. 브라우저에서 Ctrl+F5를 눌러 새 화면을 불러옵니다.

이번 변경
- 경리에게 생산 재고 알림은 보내지 않습니다. 경리 본인이 기안한 생산 재고도 포함합니다.
- 기존 생산 재고 알림도 경리 알림함·대시보드·읽지 않은 건수에서 제외합니다.
- 경리(최종 승인 문서 조회 권한)는 본인 휴가원·사무용품 구매 기안의 진행 알림을 유지합니다.
- 다른 직원의 휴가원·구매요청서에서는 승인완료·배송완료 알림만 표시합니다. 생산 재고는 경리 알림에서 제외합니다.
- 다른 직원의 검토·승인대기, 배송중·입고대기, 취소 알림은 표시하지 않습니다. 취소 문서의 완료 알림도 제외합니다.
- 기존 알림에도 같은 조건을 적용하며 알림함·대시보드·읽지 않은 건수에 동일하게 반영합니다.
- 알림은 기안자 성명 - 직급 - 문서 종류 - 처리 상태로 표시합니다. 대시보드의 최근 알림도 같습니다.
- 검토 요청은 검토대기, 검토 후 기안자에게는 검토완료, 최종 승인자에게는 승인대기, 최종 승인 후에는 승인완료로 표시합니다.
- 생산 재고는 검토완료 후 입고대기·입고완료, 사무용품은 배송중·배송완료로 구분합니다.
- 반려·취소 알림에는 상태 아래 사유를 표시하며 기존 알림의 날짜·읽음 여부를 유지합니다.
- 기존 알림 변환과 새 저장 항목 추가가 있으므로 setup.bat을 실행해 DB를 업데이트하세요.
- 새 문서 글자를 없애고 탭 배경을 주황색으로만 강조합니다. 확인 후에는 원래 색으로 돌아옵니다.
- 스타일·스크립트 버전을 갱신하여 업데이트 후 이전 화면 캐시를 다시 쓰지 않도록 했습니다.
- 문서함의 모든 부서 선택을 없애고, 직원별 연차 관리의 부서 선택은 유지했습니다.
- 엑셀 단가·총가격은 소수점 없이 천 단위 쉼표로 표시합니다(예: 111,000). 저장된 실제 금액은 유지합니다.
- 최종 승인 문서함에 전체 탭을 추가하고 처음에는 모든 종류를 함께 표시합니다.
- 확인하지 않은 새 문서가 있는 탭은 주황색 배경으로 강조합니다.
- 종류별 탭을 누르면 그 종류만 확인 처리하고, 전체를 누르면 모두 확인 처리합니다. 확인 여부는 계정별로 저장됩니다.
- 화면을 열어 둔 동안에도 15초마다 새 최종 승인·검토 완료 문서를 확인합니다.
- 직원별 연차 관리에서 부서를 선택해 조회할 수 있습니다. 저장 후에도 선택한 부서와 연도가 유지됩니다.
- 직원 목록, 결재선, 수령자 목록과 문서 목록은 이사→부장→팀장→과장→대리→주임→사원 순입니다. 같은 직급은 이름순, 같은 기안자의 문서는 최신순입니다.
- 경리의 최종 승인 문서함 → 구매요청서에서 문서를 체크하고 선택 문서 다운로드를 누르면 엑셀(.xlsx)을 받습니다.
- 엑셀 항목: 성명, 품명, 수량, 단가, 총가격, 신청사유. 내려받기는 구매·배송 상태를 변경하지 않습니다.
- 전체 선택은 현재 검색 결과에 표시된 문서(최대 100건)에만 적용됩니다.
- 확인 단계는 검토확인·승인확인으로 표시하고 초록색 체크로 강조합니다.
- 본인이 확인한 단계에는 내가 확인함을 표시합니다.
- 검토·승인 확인 성공 시 완료 팝업이 뜨며, 처리 중에는 중복 클릭을 막습니다.
- 검토자·승인자는 admin을 제외한 주임 이상 직원만 지정할 수 있습니다.
- 결재선은 부서를 먼저 선택한 뒤 그 부서의 직원을 선택합니다.
- 경리 최종 승인 문서함은 휴가원·구매요청서·생산 재고 요청으로 나눠 표시합니다.
- 글자는 처음 화면과 확대 화면의 중간 크기로 조정하고 진한 색을 유지했습니다.
- 비밀번호는 숫자만으로도 4자 이상이면 사용할 수 있습니다.
- 내 계정 메뉴에서 본인의 비밀번호를 변경할 수 있습니다.
- 직원·권한 관리를 미분류 계정과 부서별 탭으로 구분했습니다.
- 생산 재고 요청에서 단가, 총가격, 최종 승인자 항목을 없앴습니다.
- 생산 재고는 검토가 끝나면 발주 담당자에게 전달됩니다.
- 왼쪽에 '생산 재고 요청함'을 추가했습니다.
- 발주 담당자는 admin이 '구매·발주 처리' 권한을 부여한 직원입니다.
- 기존 검토 완료 재고 문서는 발주대기로 전환되며 이전 이력은 보관합니다.

프로그램 설치 창에서 오류가 나오면 실행 단계로 넘어가기 전에 오류 화면을 확인하세요.
