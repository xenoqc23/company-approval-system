# 전체 기능 통합 검증 · 2026-10-23

기존 사내결재시스템 전체와 새 구매 흐름을 하나의 애플리케이션으로 구성했다. NAS 운영 모드와 PC는 같은 구매·권한·규정·알림·화면 코드를 사용한다. 로컬의 가상 계정 생성·역할 전환만 운영에서 차단한다. 실제 NAS에 접속하거나 업데이트하지 않았다.

## 발견하고 보완한 차이

1. 구매 모듈이 로컬 플래그에서만 설치되던 구조를 수정했다. NAS 이미지의 COPY 및 Docker 빌드 컨텍스트 허용 목록에도 구매 모듈을 포함했다.
2. 기존 부서별 결재자 선택 UI를 구매 양식에 복원했다. 직급·자격 조건을 만족하는 다른 부서의 검토·승인자도 선택할 수 있다. 구매확인은 요청 부서 기준으로 별도 배정한다.
3. 요청 방식 안내는 선택에 맞춰 표시하며, 검토 경로와 직접 요청 안내가 중복되지 않는다.
4. 기존 공통·직원별·부서별 전결규정의 전체 조회·수정과 상세 경로 미리보기를 유지했다. 문서별 쉬운 규정 화면도 함께 제공한다.
5. 실제 NAS와 같은 admin 계정으로 가상 관리자를 준비해 대표 지정·결재 설정과 원래 관리 메뉴를 테스트할 수 있게 했다.
6. 구매 첨부파일을 DB와 함께 백업·복구하도록 확장했다. 목록·크기·체크섬·경로·중복 항목을 검사하고 기존 DB 전용 백업도 지원한다.
7. 새 설치·업데이트에서는 구매 정책 싱글턴만 비활성 상태로 준비한다. 담당자를 추측해 지정하거나 기존 문서·권한·비밀번호를 수정하지 않는다. 담당자 지정 및 규정 활성화 안내를 제공한다.

## 확인 결과

- 전체 통합 SQLite 검사 29개 통과.
- MariaDB 10.11에서 통합·첨부 백업·동시 승인·확인·수령 검사 40개 통과.
- 기존 workflow 호환 경로 회귀검사 319개 중 298개 통과, 환경별 검사 21개 건너뜀.
- 구매 전용 호환 경로 회귀검사 89개 중 76개 통과, SQLite 행 잠금 검사 11개와 전체 앱 전용 모듈 2개 건너뜀.
- 전체 ZIP 검사 4개 통과: 전체 소스·정적 파일·NAS 도구·CRC·SHA256, 운영과 로컬 기능 일치, 가상 데이터 격리, 초기화 보호.
- `check`, `makemigrations --check --dry-run`, Python 구문 검사 확인.
- Chromium에서 일반 검토·승인, 부서별 직접 요청, 승인·확인 동시 처리, 이사 본인 요청, 독립 검토자 알림 팝업, 대표 품목별 승인·반려·보류, 부분 수령·완료 집계, 비공개 진행·첨부 권한, 엑셀 다운로드 확인.
- 기존 관리·휴가·재고·복지·일정·규정 메뉴를 유지한 상태에서 320/390/768/1366/2560px 점검. JavaScript 오류·누락 자산 없음.
- 실제 NAS Dockerfile의 앱 소스로 운영 모드 이미지를 빌드하고 Gunicorn·WhiteNoise·MariaDB로 실행했다. 전체 원래 메뉴, admin의 대표 설정, 부서 선택, 구매 전 과정·첨부·수령을 브라우저로 확인했다. 운영에서 가상 역할 UI가 없고 전환 POST는 거부됨을 확인했다.
- 기존 workflow 스키마에 가상 직원·비밀번호·권한·연차·4가지 구매 상태·공통 규정 버전·알림·이력을 넣은 뒤 새 구매 마이그레이션을 적용했다. 기존 레코드는 모두 동일했고 새 구매 규정은 비활성 상태로 생성됐다.
- SQLite에서 실제 구매 데이터·첨부를 백업하고 임시 변경·파일 삭제 후 복구해 원본 데이터·파일과 안전 백업을 확인했다.
- 운영 MariaDB에서도 웹을 중지한 가상 환경에서 DB·첨부를 백업, 임시 변경·파일 삭제, 오프라인 복구 후 원본 상태·파일·복구 직전 안전 백업을 확인했다.
- 실제 배포 ZIP을 새 폴더에 풀어 SETUP 로직 실행. admin을 포함한 가상 직원 12명, 문서 0건, 표시 역할 10개를 확인했다. ZIP에서 직접 실행한 전체 화면도 브라우저에서 점검했다.

Windows BAT의 명령·CRLF를 검사했으며 실행은 Linux Python/Chromium과 운영 모드 Docker/MariaDB로 검증했다. 닫힌 브라우저 웹 푸시는 기존 합의대로 비활성이다. 공개 파일은 소스와 가상 화면뿐이며 실제 직원 DB·첨부·.env·비밀번호·개인키를 포함하지 않는다.
