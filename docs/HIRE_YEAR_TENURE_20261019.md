# 입사연도별 연차 산정 근무연수

연차일수표는 유지하고 적용 근무연수만 입사연도에 따라 구분한다.

- 2016년까지 입사: 조회 연도 − 입사 연도, 월·일 무시.
- 2017년 이후 입사: 조회 연도 1월 1일 기준 만 근속연수.
- 입사 첫해 입사월 포함 월수 선부여 및 다음 해 12일 규칙은 유지.
- 근무연수 표시와 엑셀도 총연차와 같은 계산을 사용한다.
- 장기근속 포상 등의 실제 만 근속기간 계산은 변경하지 않는다.

2026년 기본 일수표 예시는 2005년 6월 입사 21년/25일,
2016년 12월 입사 10년/19일, 2017년 12월 입사 8년/18일이다.

0014는 과거 AnnualPolicy에 새 계산 필드를 False로 추가하고 새 정책의 기본값은 True로 둔다.
현재 연도 규정이 없으면 직전 규정의 일수표·안내·신입 규칙을 복사한다.
현재·미래 규정만 새 계산으로 변경하고 버전과 감사 이력을 기록한다.
현재·미래 자동 총연차 중 대상 입사연도 직원만 재계산한다.
수동 총연차, 사용연차, 과거 잔액 및 모든 문서·사용내역은 보존한다.
마이그레이션을 다시 호출해도 같은 잔액에 반복 가산하거나 이력을 중복 생성하지 않는다.

기존 수동 총연차를 대체하려면 관리자가 재계산 미리보기의 수동값 대체 확인을 사용한다.
기존 승인·취소 트랜잭션과 연차 동기화는 같은 entitlement 함수를 사용한다.

`packaging/build_hire_year_tenure_patch.py`는 직전 공통 규정 패치를 포함한 ZIP을 생성한다.
기존 소스 백업, 체크섬 검사, 이전 이미지 DB 백업이 끝난 뒤 0014를 실행한다.
기존 0011을 재배포하거나 직원 데이터·.env·비밀번호를 묶지 않는다.
