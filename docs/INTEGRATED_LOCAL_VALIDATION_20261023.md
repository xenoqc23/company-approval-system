# 통합 로컬 테스트 검증 기록 · 2026-10-23

이번 변경은 기존 XENOSYS 사내결재 화면에 구매요청 흐름을 연결한 가상 데이터 로컬 테스트입니다. 운영 모드에서는 통합 플래그가 활성화되지 않습니다. NAS 배포 파일이나 운영 DB 이관을 포함하지 않습니다.

- 실행: `SETUP_LOCAL_INTEGRATED.bat` → `RUN_LOCAL_INTEGRATED.bat`, 기본 포트 18117.
- 이전 테스트와 별도 폴더·SQLite·쿠키·알림 저장 범위·백업 경로 사용.
- 새 통합 테스트는 12개 가상 계정을 생성하고 필요한 10개 역할만 선택기에 표시. 문서는 빈 상태에서 시작하며 실제 직원 자료는 포함하지 않음.
- 기존 휴가원·생산 재고·연차·일정·복지 화면 유지. 새 구매요청을 공통 홈·결재함·내 문서함·완료 미확인·검색·알림함에 연결.
- 기존 구매문서 원본은 변경하지 않음. 취소·반려된 예전 구매문서의 재작성은 새 양식에 내용을 불러오고 구매처와 결재선을 다시 확인함.
- 휴가원·구매요청·생산 재고 규정을 분리. 구매 담당자 지정은 공통 직원·권한 관리에서만 변경.
- 구매요청함에서 요청할 품목·보낸 요청·보류를 확인. 중복 건수 카드와 별도 구매 모아보기·보류함 메뉴 제거.
- 구매 상태 검색은 7개 이하의 핵심 그룹, 중복 승인완료 레이블 제거. 구매 담당자 요청 대기 화면은 품목 선택에 필요한 열만 표시.
- 담당자 변경 시 진행 문서는 기존 경로 유지. 수령 대기 업무가 남은 구매 담당자 해제 차단. 대표 실제 승인 권한과 일치시킴.
- 독립 알림 커서로 기존 결재와 구매 알림의 번호 충돌 방지. 구매 최종 승인만 기안 완료 미확인에 합산. 알림 읽음과 완료 확인은 별도.
- 대표 품목별 승인·반려·보류, 승인 시 자동 완료 알림, 부분 수령과 최종 수령, 구매 담당자 문서의 최신 수령 집계 유지.
- 금액 변경 재승인·기존 요청 스냅샷·품목별 결정 보존. 엑셀에 구매처·구매사유·결정·수령 현황 포함, 수식처럼 시작하는 입력을 문자로 저장.
- 구매 확인 코드가 기존 문서의 확인창을 가로채던 충돌을 수정해 기존 재고 수령 확인창 유지.
