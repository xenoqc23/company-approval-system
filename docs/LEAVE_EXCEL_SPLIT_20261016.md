# 개인 사용내역과 공용연차 내역 분리

기존 엑셀의 사용내역 한 열에 개인 휴가와 공용연차가 섞여 표시되던 부분을 두 열로 분리한다.
연도별 연차 현황 및 인원별 연차표 양쪽에 적용한다.

| 개인 사용내역 | 공용연차 내역 |
| --- | --- |
| 10/16(연차), 9/1(반차), 8/28(외출) | 5/4(공용연차) |
| — | 5/4(공용연차) |

개인 사용내역에는 결재 완료된 개인 휴가와 취소하지 않은 경리 직접 등록만 포함한다.
공용연차 내역에는 해당 직원의 활성 공용연차 차감만 포함한다.
기존 연도·부서 범위, 날짜 내림차순, 취소 제외, 여러 날의 평일별 표시를 유지한다.
두 열 모두 줄바꿈과 필터를 적용하고, 더 긴 내역을 기준으로 행 높이를 맞춘다.
공용연차 일수와 총연차·사용연차·잔여연차의 숫자 및 산정 기준은 변경하지 않는다.

## NAS 적용

`releases/xenosys-leave-excel-split-20261016.zip`을 File Station의
`/docker/company-approval`에 업로드하고 ‘여기에 압축 풀기’를 선택한다.
Windows PowerShell에서 실행한다.

```powershell
ssh -t admin@192.168.1.46 "sudo sh /volume1/docker/company-approval/xenosys-leave-excel-split-20261016/APPLY_LEAVE_EXCEL.sh"
```

`LEAVE_EXCEL_READY` 후 사이트를 새로고침하고 엑셀을 다시 다운로드한다.
기존에 다운로드한 엑셀 파일은 자동으로 바뀌지 않는다.

앞선 직접 등록 및 엑셀 업데이트를 포함한 런타임 파일 14개 묶음이다.
기존 연차 산정 코드·.env·비밀번호·HTTPS 설정은 교체하지 않는다.
기존 파일은 `.leave-excel-backup.XXXXXX`에 보관하고, 기존 nas.sh update로 DB 백업 및 웹 전환을 수행한다.
운영 NAS 자체 적용은 별도로 완료 표시와 새 엑셀을 확인해야 한다.

## 검증

- SQLite 관련 시험 8개 통과: 실제 XLSX 다운로드, 두 시트의 분리된 열/필터/줄바꿈,
  공용연차만 있는 직원, 경리 직접 등록/취소, 날짜·연도 범위, 숫자·잔액·부서 필터 보존.
- MariaDB 10.11.14에서 엑셀 시험 6개 통과.
- 신규 분리 버전 ZIP에 기존 설치 스크립트 시험 3개 통과: 복사/백업/설정 보존,
  손상 파일 및 진행 중 복구 차단, 실패 시 완료 표시 없이 백업 보존.
- 시스템 검사, 마이그레이션 변경 없음 확인, diff 공백 검사 통과.
- 새 DB 변경과 연차 값 재계산은 없다. 가상 직원만 사용해 검증했다.
