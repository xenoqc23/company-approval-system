테스트 순서
① 기안자 → 구매요청서 작성. 구매처·수량·금액·구매사유를 입력하고 검토자와 승인자를 확인하여 제출합니다.
② 검토자 → 결재함 → 검토 완료. 승인자에게 전달합니다.
③ 승인자 → 결재함 → 최종 승인. 기존 기안·검토·승인 카드가 완료됩니다.
④ 구매 품목확인자 → 구매요청승인완료함. 모든 부서의 승인완료 문서를 봅니다.
   상단 칸: 승인완료 / 구매 품목 확인 대기 / 취합·보고 대기. 누르면 해당 문서만 조회합니다.
   표에서도 승인 상태 / 구매 품목 확인 / 취합·보고를 따로 표시합니다.
   문서를 열어 ‘구매 품목 확인’을 눌러야 취합·보고 담당자에게 전달됩니다.
⑤ 취합·보고 담당자 → 확인된 품목 선택 → 선택 품목 요약·보고 → 대표님께 구매요청.
   부서·요청자·품목·구매처·수량·금액·구매사유·원문 링크를 확인합니다.
⑥ 대표 → 구매요청함 → 각 품목에 구매승인 / 구매반려 / 구매보류를 선택합니다.

   ‘구매 검토 결과 확정’을 눌러 결정합니다. 여러 품목의 결과를 다르게 정할 수 있습니다.
⑦ 취합·보고 담당자가 승인된 품목의 실제 결제 완료를 기록합니다. 실제 카드·은행 결제를 실행하는 기능은 아닙니다.
⑧ 기안자는 이번에 받은 수량·보관 위치를 입력하고 ‘수령 확인’을 누릅니다. 미수령 수량이 0개가 되어야 수령완료됩니다.
