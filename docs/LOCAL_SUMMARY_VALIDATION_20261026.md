# 경리 구매 집계 로컬 검증

대상: xenosys-local-summary-20261026.zip. 실제 NAS에 접속하거나 업데이트하지 않았다.

## 자동 검사

- SQLite 통합 82건 통과: 집계 11건과 기존 구매 결제·문서함·새 요청·검토·휴가원·권한 관련 회귀 검사 포함.
- 집계 검사는 경리 전용 권한·권한 해제, 기존 담당 범위 밖 문서 차단, 한국 시간의 시작일/종료일 포함, 결제 완료 등록일 기준, 반려/보류/대기/날짜 불명 품목 제외, 수령 완료 포함을 확인했다.
- 팀·복수 직원 필터, 인사 이동 후 기안 당시 부서 유지, 중복 선택 중복 합산 방지, Decimal 소수 금액, 잘못된 조건에서 전체 내역으로 돌아가지 않는 동작을 확인했다.
- 26개 내역에서 화면은 25개씩 나눠도 총액과 엑셀은 전체 내역을 포함하는지 확인했다.
- 엑셀 두 시트·선택 조건·수량/가격/용도와 텍스트 수식 방어를 확인했다. 집계 조회는 결제·수령 상태와 이력을 변경하지 않는다.
- 패키징 4건: 전체 소스/자산/NAS 도구 포함, 실제 데이터·비밀번호·환경 파일 제외, 해시/CRC, v6 포트·쿠키·데이터와 초기화 범위를 확인했다.
- Django check, 미반영 migration 없음, Python compileall, 구매 JavaScript 구문, git diff 공백 검사를 확인했다. 이번 기능은 DB 스키마 변경이 없다.

## 실제 ZIP 설치와 브라우저

새 폴더에 ZIP을 풀어 가상 직원 12명·문서 0건으로 설치됨을 확인했다. 그 후 검증용 가상 구매를 서비스로 생성했으며 해당 DB와 파일은 배포 ZIP에 넣지 않았다. Python 가상환경만 실행 환경에 연결했다.

Chromium에서 다음을 확인했다.

- 이번 달 전체: 개발팀 300,000원 + 품질팀 150,000원 = 450,000원 / 2건.
- 개발팀 과장·품질팀 팀장을 함께 선택: 이번 달 300,000원, 이전 달까지 기간 확장 시 400,000원.
- 품질팀 직원 2명 선택: 250,000원 / 2건. 현재 조건의 엑셀도 같은 2개 품목과 250,000원을 포함한다.
- 전체 직원으로 초기화하면 기간 내 총 550,000원 / 3건. 이번 달 버튼으로 450,000원으로 돌아간다.
- 수령 완료 품목은 포함되고 결제 대기 품목은 제외된다.
- 320·390·768·1440px에서 페이지 가로 넘침이 없다. 모바일 구매내역은 카드 형태로 수량·금액·용도를 보여준다.
- 잘못된 기간에는 오류를 보여주고 합계나 엑셀 링크를 표시하지 않는다. JavaScript 오류가 없다.

재현 스크립트: packaging/check_summary_local.py. 별도로 준비한 가상 자료와 loopback 주소에서만 사용한다.

실행 검증은 Linux Python/Django/Chromium에서 수행했다. Windows BAT의 명령·CRLF는 검사했지만 실제 Windows PC 실행은 직접 검증하지 않았다. Python 3.10 이상과 첫 설치 시 패키지 다운로드가 필요하다. 실제 직원·문서·비밀번호·키는 포함하지 않는다.
