# 사내결재 화면·구매 담당자 설정 수정 · 2026-10-26 v2

2026-10-26 구매 통합 업데이트가 적용된 NAS에서 사용하는 전체 앱 수정본입니다. 새 DB 변경은 없습니다. 현재 직원·규정·구매 담당자 설정과 진행 문서·이력을 유지합니다.

## 수정 내용

1. 로그인 화면의 ‘아이디 저장’ 체크박스와 문구를 한 줄로 정렬했습니다. 비밀번호 저장 방식과 로그인 세션 정책은 유지합니다.
2. 직원·권한 관리의 구매 업무 담당자 설정을 펼쳐 보여줍니다. 개발팀 요청 / 그 외 부서 요청의 구매확인 담당자는 부서·직급에 관계없이 활성·가입 승인된 직원 중 관리자가 선택할 수 있습니다. 본인 요청을 대신 확인할 수 있도록 두 담당자는 서로 다른 직원으로 지정합니다. 대표 계정은 구매확인 담당자에서 제외합니다. 변경 내용은 새 요청부터 적용하고 진행 중인 문서의 담당자·이력은 유지합니다.
3. 기안 작성 화면에서 휴가원·구매요청서·생산 재고 요청을 같은 카드로 선택합니다. 구매요청서 선택 시 새 작성 페이지로 이동하지 않고 입력 영역을 전환합니다. 문서 종류를 바꾸어도 작성하던 내용과 첨부 선택이 유지됩니다. 구매요청의 저장·검토·구매확인·결제·집계는 기존 구매 처리 서비스를 사용합니다.

정기 업데이트 명령에 직원 이름을 다시 넣을 필요가 없습니다. 기존에 저장된 담당자·권한·규정 사용 상태와 복수 구매 담당자 설정을 그대로 유지합니다. 새 계정을 생성하거나 부서·직급을 바꾸지 않습니다. 검토자 승인완료 권한과 직급별 요청 방식도 변경하지 않습니다.

## NAS에 올리기

1. 원본 `xenosys-nas-compose-update-20261026-v2.zip`을 File Station의 `docker/company-approval/updates`에 업로드합니다.
2. 업로드 완료 후 NAS에서 ZIP을 직접 압축 해제합니다. 추출 대상은 `updates` 폴더입니다. 압축을 푼 PC 폴더를 옮기다 일부 하위 파일이 누락되지 않도록 원본 ZIP을 사용합니다.
3. 다음 파일 위치를 확인합니다.

```text
docker/company-approval/updates/xenosys-nas-compose-update-20261026-v2/
├─ app/
├─ README.md
├─ RELEASE.json
├─ SHA256SUMS
└─ UPDATE_NAS.sh
```

기존 설치 폴더의 `app`, `data`, `backups`, `.env`에 직접 덮어쓰지 않습니다. 기존 설치 경로와 Docker 프로젝트가 기본값(`/volume1/docker/company-approval`, `xenosys_approval`)인 구성을 사용합니다. 사용자 지정 설치라면 기존 `APPROVAL_BASE`, `APPROVAL_PROJECT` 값을 지정합니다.

## 점검과 적용

기존에 사용한 NAS SSH 창에서 실행합니다. `admin`은 사내결재 시스템의 관리자 아이디입니다. 다른 아이디를 사용하면 해당 값으로 바꿉니다.

```sh
cd /volume1/docker/company-approval/updates/xenosys-nas-compose-update-20261026-v2
sudo sh UPDATE_NAS.sh precheck --operator admin
```

파일 검증·이미지 준비·기존 계정·진행 문서 점검을 통과하면 업무 입력이 없는 시간에 적용합니다.

```sh
sudo sh UPDATE_NAS.sh update --operator admin
```

업데이트는 사전 점검 후 웹 중지 → 기존 데이터·첨부 기준값 저장 → 기존 이미지로 백업 → DB 변경 확인 → 기존 데이터·첨부 보존 비교 → 기존 구매 설정 유지 → 앱 검사 → 웹 시작·상태 확인 순서로 진행합니다. 빌드와 사전 점검 실패 시 기존 웹은 계속 실행됩니다. 웹 중지 후 실패하면 자동 재개하지 않습니다.

`Release file verification failed`와 `No such file or directory`가 나오면 누락된 배포 파일이 있는 상태입니다. 원본 ZIP을 NAS에서 다시 압축 해제하고 파일 검증이 통과한 뒤 재개합니다. 검증 목록을 삭제하거나 건너뛰지 않습니다.

## 적용 후

기존 접속 주소에서 Ctrl+F5로 새로고침한 뒤 확인합니다.

- 로그인: 체크박스와 ‘아이디 저장’ 문구가 같은 줄에 정렬되는지 확인합니다.
- 기안 작성: 세 문서 종류가 같은 화면에서 선택되고, 종류를 바꾸어도 작성 내용과 구매 첨부가 유지되는지 확인합니다.
- 구매요청: 구매 링크·검토자 검증, 임시저장·제출·기존 검토/구매확인 흐름을 확인합니다.
- 직원·권한 관리: 다른 부서·직급의 직원도 구매확인 담당자로 선택 가능한지 확인합니다. 기존에 지정한 담당자와 규정은 유지됩니다.
- 기존 문서·연차·진행 결재와 구매 집계·엑셀을 확인합니다.

문제가 있으면 업데이트 직전 이미지와 백업으로 함께 복구할 수 있습니다. 복구는 백업 이후 입력한 내용을 되돌리므로 업무 재개 전에 판단합니다.

```sh
sudo sh UPDATE_NAS.sh rollback
```

이 ZIP에는 실제 직원 이름·DB·비밀번호·가상 직원 생성기·테스트 문서·협업일지가 포함되지 않습니다. 실제 NAS의 적용과 현장 확인은 관리자가 진행합니다.
