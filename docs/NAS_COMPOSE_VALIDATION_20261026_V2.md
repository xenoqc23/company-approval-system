# 기안 화면·구매 담당자 설정 수정 검증

2026-10-26. 실제 NAS에 이 수정본을 적용하지 않았으며, 기존 NAS 업데이트가 완료된 상태에서 사용할 후속 파일을 준비했다.

## 수정 범위

- 아이디 저장 체크박스/문구를 한 줄로 정렬. 기존 서명 쿠키·브라우저 암호 자동입력·CSRF·로그인 세션 동작 유지.
- 구매확인 담당자 후보를 활성·가입 승인된 일반 직원으로 확장. 부서/직급 제한을 제거하고 관리자만 저장 가능. 두 담당자는 본인 요청 대체 확인을 위해 서로 다르게 지정. 대표는 확인 담당자에서 제외. 기존 진행 문서의 담당자/이력 보존.
- 하나의 기안 화면에서 휴가원·구매요청서·생산 재고를 전환. 구매 입력에 별도 필드 이름을 사용해 문서/구매 양식 충돌을 방지하고 기존 저장·권한·결재 서비스를 유지. 입력 및 첨부는 화면 전환 시 유지.
- 일반 NAS 후속 업데이트에서 현재 구매 담당자·복수 구매 담당자·규정 사용 여부·요청 직급·검토자 권한을 유지. 역할을 명시해 초기 적용하는 경우에만 계정 연결과 규정 적용 수행.

## 확인 결과

- MariaDB 통합 검사 139건 통과: 공유 기안 화면, 요청 저장, 구매 권한·결재·결제·집계·엑셀·로그인/CSRF·동시 처리·NAS 데이터 보존 등.
- 기존 업무 검사 322건: 301건 통과, SQLite에서 실행할 수 없는 별도 환경 전용 검사 21건 제외.
- 구매 설정 유지 추가 검사 8건 통과: 규정 사용 안 함, 직접 요청 직급, 복수 구매 담당자와 버전 보존, 부서·직급과 관계없는 구매확인 담당자 지정 등.
- 배포 무결성·NAS 실행 순서 검사 5건 통과: ZIP의 새 템플릿·스크립트 포함, 파일 검증, 백업·보존 비교 순서, 사전 점검 실패 시 기존 웹 유지, 보존 비교 실패 시 정지 유지와 복구 표식 확인.
- Chromium 운영 모드 검증: 체크박스/문구 세로 중심과 크기, 세 종류 전환 시 새 문서 요청 없음, 작성 내용·파일 선택 유지, 중복 DOM ID 없음, 구매 금액 계산·필수 링크·검토자·첨부 제출, 관리자에 의한 사원급 구매확인 담당자 변경·저장 확인.
- 같은 화면의 휴가원·생산 재고를 기존 결재 서비스로 실제 제출 확인. 숨겨진 구매 입력의 필수 항목이 다른 양식 제출을 막지 않음.
- 390/768/1440 너비에서 문서 종류별 화면 가로 넘침 없음.
- 운영 Docker 이미지 빌드·기동·DB 상태·앱 검사 통과. 가상 NAS 후속 업데이트 절차에서 사원급 구매확인 담당자와 기존 설정·문서·첨부 보존 비교 통과.
- 모델 변경 누락 없음, 앱 검사·자바스크립트 구문 검사·diff 공백 검사 통과.

프로젝트의 QA용 인증서로 네트워크 신뢰를 맞춘 Docker 빌드와 가상 DB에서의 구동을 사용한다. 인증서·DB·암호·가상 직원·개인 문서·협업일지는 배포 파일에 넣지 않는다. 실제 NAS 적용 후 기존 주소에서 새로고침하여 권한별 문서 작성과 기존 자료를 최종 확인한다.
