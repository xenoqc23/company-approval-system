Xenosys 사내결재 — 문서·연차 개선 4종 NAS 업데이트 (2026-10-20)

설치
1. ZIP을 File Station /docker/company-approval에 업로드합니다.
2. 우클릭 → 여기에 압축 풀기. 기존 app·data·.env를 지우지 않습니다.
3. Windows PowerShell에서 아래 명령을 실행합니다.

ssh -t admin@192.168.1.46 "sudo sh /volume1/docker/company-approval/xenosys-document-updates-20261020/APPLY_DOCUMENT_UPDATES.sh"

4. NAS 관리자 비밀번호를 입력합니다. 두 번 물을 수 있습니다.
5. DOCUMENT_UPDATES_READY가 나오면 사이트를 새로고침합니다.

1. 내 기안 결재완료 확인
- 홈 결재 진행 상태에 ‘결재완료 · 미확인 N건’을 추가합니다.
- 클릭하면 내 기안의 미확인 완료 문서를 보여줍니다. 완료 문서 전체도 선택할 수 있습니다.
- 목록이나 알림함 모두 읽음만으로는 숫자를 없애지 않습니다. 해당 문서를 열면 그 문서만 확인 처리됩니다.
- 기안자의 확인과 경리 담당자의 확인은 별도로 보관합니다.
- 기존에 읽은 승인완료 알림은 이전하여 새 미확인으로 반복 표시하지 않습니다. 기존 확인 근거가 없는 완료 문서는 미확인으로 표시됩니다.
- 최종 승인 취소·삭제된 문서는 완료 미확인 건수에서 제외됩니다.

2. 경리 담당자의 승인 휴가 정정
- 기존 연차관리 권한(manage_leave)이 있는 담당자는 승인된 휴가원 상세 → 휴가 사용내역 정정을 사용합니다.
- 실제 휴가 종류·날짜·시간과 필수 정정 사유를 입력 → 변경 내용 미리보기 → 정정 저장 순서입니다.
- 예: 연차1일을 오전반차0.5일로 정정하면 기존1일을 복구하고0.5일을 차감하여 잔여가0.5일 증가합니다.
- 문서의 연도별 실제 차감 기록으로 처리합니다. 연도가 바뀌는 정정도 해당 연도별 잔액에 반영합니다.
- 원래 결재자·결재선·승인 시각·신청 사유를 바꾸지 않습니다. 최초/이전 사용정보·변경정보·처리자·일시·사유를 보존합니다.
- 사용내역·달력·연차 엑셀은 정정된 실제 사용정보를 표시합니다.
- 기안자와 경리 담당자에게 정정 알림을 보내고 다시 NEW/미확인으로 표시합니다.
- 중복 저장·동시 정정·승인 취소와의 동시 처리에서 중복 차감/복구를 막습니다.
- 정정 후 최종 승인을 취소하면 정정된 현재 차감량만 복구합니다.
- 실제 휴가를 전혀 쓰지 않았다면 기존 최종 승인 취소를 사용합니다.

3. 취소 문서 삭제 및 보관
- 기안자 본인, 시스템 관리자, 최종승인문서 조회 담당자는 취소 문서를 삭제할 수 있습니다.
- 연차관리 담당자는 취소된 휴가원을 삭제할 수 있습니다. 일반 검토자/승인자라는 이유만으로 타인 취소 문서를 삭제할 수 없습니다.
- 삭제는 일반 목록·검색·알림에서 숨기는 처리입니다. 문서와 결재·취소·정정 이력은 DB에 남습니다.
- 관리자에게 ‘삭제 문서 보관함’을 제공합니다. 기존에 삭제한 문서도 관리자 보관함에서 확인할 수 있습니다.
- 취소 시 복구한 연차는 삭제 때 다시 복구하지 않습니다. 승인 완료 상태인 문서를 삭제하려면 먼저 최종 승인을 취소해야 합니다.

4. 품목 입력 시 유사 구매 안내
- 사무·사내용품/생산 재고 작성 시 품목을2글자 이상 입력하고 잠깐 멈추면 유사 품목을 안내합니다.
- 띄어쓰기·대소문자·하이픈 차이를 정리하고 품목명과 입력한 모델명·규격 단어로 찾습니다. AI 의미 추론 방식은 아닙니다.
- 결재 진행 중·승인·발주·배송/입고완료된 과거 전 기간을 대상으로 검색합니다.
- 진행 중/미입고 요청을 먼저, 완료 내역은 최신순으로 최대8건과 전체 일치 건수를 표시합니다.
- 임시저장·반려·취소·삭제 문서와 현재 작성 중인 문서는 제외합니다.
- 표시 정보는 부서·품목/규격·수량·요청일·상태뿐입니다. 문서 전체·신청 사유·금액·구매 링크·직원 이름을 공개하지 않습니다.
- 기존 문서 전체 열람 권한은 유지됩니다. 결과가 있어도 구매요청을 계속 제출할 수 있습니다.
- 작성 시 ‘기밀 구매’를 체크하면 다른 직원의 유사 구매 안내에서 해당 품목을 제외합니다.
- 기존 구매품목은 공유 검색 대상에 포함합니다. 배송완료가 현재 재고를 뜻하지 않는다는 안내를 표시합니다.

보존 및 누적 반영
- 기존 직원·암호·입사일·생일·문서·전결규정·연차 잔액·직접/공용 사용내역·문서별 확인 기록을 초기화하지 않습니다.
- 0020은 새 필드·정정 이력·기안자 확인 테이블과 품목 검색용 파생값을 추가합니다. 기존 승인 시각·차감액·확인 기록을 변경하지 않습니다.
- 선행0011 설치가 필요합니다. 이전0012~0019 누적 포함, 적용된 마이그레이션은 재실행하지 않습니다.
- 기존 화면 팝업·알림음·실시간 건수·경리 문서별NEW를 유지합니다. 브라우저 닫은 뒤 웹 푸시는 계속 보류하며 설정/Windows 테스트 버튼을 숨깁니다.
- 실제 직원·생일·DB·비밀번호·.env·푸시 비밀키는 ZIP에 포함하지 않습니다.
- 체크섬 검증 → 기존 소스 .document-updates-backup.XXXXXX 보관 → 기존 nas.sh update 순서입니다.
- 기존 nas.sh가 새 이미지 빌드 후 이전 이미지로 DB를 백업하고 마이그레이션·웹 전환을 합니다.
- .env·HTTPS·접속 주소·Docker Compose·예약 백업을 덮어쓰지 않습니다.
- 다른 업데이트·복구 진행 중이면 중단합니다. 설치 중 잠깐 접속이 끊길 수 있습니다.
- 실패 시 READY를 출력하지 않습니다. 출력/백업 경로를 보관하고 데이터 삭제·재설치·임의 복원을 하지 마세요.
