# 운영 배포용 화면 문구 검토안

작성일: 2026-10-15. 사용자 요청에 따라 문구 수정안만 정리했다. 아래 문구는 아직 템플릿·JavaScript·서버 메시지에 적용하지 않았다. 기능 구현·NAS 설정·운영 배포도 수행하지 않았다.

표현 원칙은 짧은 상태 안내, 필요한 다음 행동, 용어 일관성이다. ‘경리가 입력한’처럼 내부 입력 주체를 설명하는 문구는 생략하거나 ‘등록된 정보’로 표현한다. 기능 제한·권한 조건·자료가 없다는 사실은 그대로 전달한다. 사용자에게 불필요한 구현 설명은 직원 화면에서 줄이고 필요한 운영 정보는 관리자 화면과 운영 문서에 남긴다.

## 기능 준비와 함께 처리할 문구

- 백업 화면의 ‘시안 데이터 백업’을 ‘운영 데이터 백업’으로 바꾸는 작업은 MariaDB 백업 연결·복구 검증이 끝난 뒤에 한다. 현재 SQLite 전용 버튼을 문구만 바꿔 운영 백업으로 안내하지 않는다.
- 보류된 전결규정과 처리 예외는 문구만 지워 확정된 규정처럼 안내하지 않는다. 최종 운영 규칙 확인 후 직원 안내와 관리자 설정을 함께 정리한다.
- ‘예시’라는 단어가 입력 예를 설명하는 경우는 유지한다. 예: 품목 입력란의 ‘예: A4 복사용지’.
- 일반 직원 안내의 표현을 다듬어도 경리·admin의 권한, 실제 계산, 변경 이력은 바꾸지 않는다. ‘경리’ 문자열을 일괄 치환하지 않는다.
- 같은 안내를 HTML과 JavaScript가 각각 표시하는 경우 두 경로를 함께 반영한다. 문구 변경 후 실제 화면과 빈 목록·오류·성공 안내를 확인한다.
