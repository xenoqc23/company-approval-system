# 구매요청 로컬 테스트 검증 (2026-10-22)

로컬 전용 테스트 브랜치이며 NAS 배포 브랜치·운영 데이터는 변경하지 않았습니다.

- SQLite: 구매 업무 테스트 66개, 58개 통과·행 잠금 전용 8개 제외.
- MariaDB 10.11: 같은 66개 모두 통과. 승인 확정 중복, 금액 변경과 수령 동시 요청, 중복 부분 수령을 포함합니다.
- 기존 시스템: workflow 테스트 319개, 298개 통과·환경에 해당하지 않는 21개 제외.
- 배포 ZIP: 7개 검사 통과. 소스·체크섬·파일 제외·Windows 배치 줄바꿈·독립 쿠키·가상 데이터 초기화 보호를 확인했습니다.
- Chromium 실제 화면: 기안→검토→승인, 품목 확인, 비공개 구매 증빙, 취합 보고, 품목별 승인·반려·보류, 별도 결제 확인 없는 수령, 부분 수령을 확인했습니다.
- 추가 실제 화면: 보완 요청·자료 업로드, 전체 승인 후 일부 보류, 미확인 완료 건수 1→0, 금액 감소 이력, 금액 증가 재승인, 보류 품목 재보고, 이전 보고서 불변을 확인했습니다.
- 320·390·768·1366·2560px에서 화면 바깥 넘침이 없고, JavaScript 오류·누락 정적 파일이 없음을 확인했습니다.

예시 화면은 전부 가상 계정·가상 구매 데이터입니다. ZIP에는 계정 비밀번호·DB·업로드 자료·.env·비밀키가 포함되지 않습니다. 첫 실행 때 새 비밀번호와 빈 가상 데이터를 준비합니다.

대표 구매승인은 실제 카드·은행 결제를 기록하는 의미가 아닙니다. 승인 직후 기안자는 수령 대기 상태이며, 실제 수령 수량을 입력해야 수령 완료가 됩니다.
