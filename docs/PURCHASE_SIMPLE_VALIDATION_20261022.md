# 구매요청 화면 간소화 검증 (2026-10-22)

로컬 테스트 전용입니다. NAS 배포 브랜치와 운영 자료를 수정하지 않았습니다.

- 구매 테스트 68개: SQLite에서 60개 통과, 별도 행 잠금 환경용 8개 제외.
- 새 UI에서도 검토→승인→구매 내용 확인→모아서 구매요청→품목별 구매 결정→부분 수령을 실제 Chromium으로 확인했습니다.
- 보완 자료 업로드, 전체 승인 후 일부 보류, 미확인 완료 건수, 금액 감소 이력, 증가 시 재승인, 보류 후 다시 요청, 이전 보고서 보존을 확인했습니다.
- 실제 브라우저에서 파란 진행 중·주황 대기·녹색 완료·회색 취소 배경색과 상태 문구를 함께 확인했습니다.
- 주요 작업 하나 강조, 추가 작업 접힘, 역할별 홈, 대표의 개인 현황 미표시, 구매승인과 수령의 별도 표시를 확인했습니다.
- 받은 수량 입력칸은 처음에는 비어 있습니다. 수량 확인창에서 취소 후 다시 제출해도 정상이며 부분 수령 수량을 중복 계산하지 않습니다.
- 320·390·768·1366·2560px에서 확인했으며 JavaScript 오류와 누락된 정적 파일이 없습니다.
- ZIP 검사 7개와 실제 압축 해제 후 최초 준비·초기화·로그인·기안 작성·첨부파일 다운로드를 통과했습니다.
- 새 ZIP은 별도 폴더·18113 포트·독립 쿠키로 시작하며 계정 비밀번호·DB·.env·업로드 자료를 포함하지 않습니다.

실제 화면 예시는 purchase-simple-examples 디렉터리에 있으며 전부 가상 정보입니다.
