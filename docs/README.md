2026-10-15 추가 계획: [본문 17장](company_approval_project_report_20261014.md#17-추가-변경-계획--다음-일괄-반영-대상)과 Word 문서에 ‘오른쪽 결재 진행 상태에는 진행 중인 기안만 표시’ 요구사항을 추가했습니다. **구현·시연은 보류** 상태이며 다음 변경사항과 함께 반영합니다. PDF는 2026-10-14 원본으로, 이 추가 계획은 포함하지 않습니다.


2026-10-15 전결규정 추가 논의: 본문과 Word 문서의 **17.2 전결규정 관리 — 설계 초안**에 사용자 방향, 구매/휴가 예시, 추천 설정 방식 및 미확정 항목을 구분하여 기록했습니다. 구현·시연은 보류하며, 금액 경계·허용 직급·자기 승인 등은 후속 논의에서 확정합니다. PDF에는 이 초안이 포함되지 않습니다.


전결 후속 결정: ‘부장급까지’는 주임~부장 중 선택(사원·이사 제외)으로 기록했습니다. **17.3 기존 결재와 전결규정의 통합 계획**에는 기본 경로 유지, 새 제출 시 경로 확정, 기존 문서 보존, 연차·취소·알림·진행 상태의 일관성을 설계 제안으로 추가했습니다. 코드 변경과 시연은 수행하지 않았습니다.


전결 추가 확정: **17.4 승인자의 직급 하한**에 ‘승인자는 기안자와 같은 직급 이상이며 전결 허용 범위도 만족해야 함’을 기록했습니다. 검토자 하한과 후보자 부재 시 처리는 별도 논의 항목으로 유지합니다. 본인 승인에 관한 후속 결정은 17.5를 따릅니다. 계획서와 Word만 갱신했습니다.


전결 보완 항목 최신 결정은 **17.5**에 정리했습니다. 본인 최종 승인과 검토 생략 문서의 승인 전 기안자 삭제는 허용합니다. 100만원 초과 구매와 적격 승인자가 없을 때의 처리는 보류하며, 규정 적용 미리보기는 후속 결정으로 도입을 확정했습니다(17.6). 구현·시연 없이 계획서와 Word만 갱신했습니다.


**17.6**: 규정 적용 미리보기 도입, 경리의 연차규정·경조사비 편집, 근속기간별 연차일수표와 자동 총연차 산정 연동을 추가했습니다. 올해 기존 연차의 미리보기 후 적용과 수동 수정값 확인 방식은 후속 결정으로 확정했습니다(17.7). 규정 적용 시점은 별도 논의합니다. 계획서와 Word만 갱신했으며 구현·시연은 수행하지 않았습니다.


**17.7**에 올해 연차의 미리보기→직원 선택→재계산 적용을 확정했고, **17.8**의 규정 적용 연도 표시·관리 메뉴 정리·장기근속 포상 기준 편집·공용연차 중복 안내는 후속 사용자 동의로 도입 방향을 확정했습니다. 코드·데이터·실행 패키지는 변경하지 않았습니다.


**17.9**의 검토자·승인자의 직급 관계, 입사일 미등록 직원 표시, 중도 입사자의 공용연차 대상 기준은 후속 사용자 동의로 확정했습니다. 공용연차는 입사일 이전을 제외하고 입사일 이후 휴무만 차감하도록 계획합니다. 앞서 17.8의 네 가지는 도입 확정이며, 구현·시연은 계속 보류합니다.


**현재 구현 상태는 18장**을 확인하세요. 사용자의 일괄 구현 요청에 따라 확정 사항을 PC 검토본에 반영했습니다. 17장의 ‘구현 보류’ 문구는 당시 계획 단계 기록입니다. Word와 본문 텍스트에 구현 결과·보류 사항·검증 범위를 추가했고 PDF는 최초 보고서입니다.
