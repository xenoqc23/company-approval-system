# 휴대폰 화면 적용 — 2026-10-16

PC 화면의 최소 너비 1,080px 때문에 휴대폰에서도 넓은 작업 화면이 축소되어 보였다. 1,080px 미만에서는 모바일 배치로 전환하고, 600px 이하의 문서 목록은 표의 모든 정보를 카드 안에 배치한다. URL과 직원 계정은 그대로 사용한다.

- 상단 전체 메뉴와 하단 홈·결재함·기안·내 문서·내 계정 메뉴.
- 화면에 맞춘 로그인·가입·계정, 연차 현황, 문서 종류별 빠른 신청.
- 한 열로 배치한 휴가·구매·재고 작성 및 문서 상세·처리 버튼.
- 달력과 읽기 쉬운 월별 일정 목록, 직원·권한·규정 관리 화면.
- 휴대폰 입력 글자 16px 이상, 주요 버튼 44px 이상. 화면 확대는 제한하지 않는다.
- 권한에 따라 구성한 기존 전체 메뉴를 모달 안에서 재사용한다. 닫기·Escape·바깥 영역·PC 크기로 변경 시 닫으며 초점을 복원한다. JavaScript가 없으면 원래 메뉴가 페이지 상단에 표시된다.

## 검증

운영 NAS와 분리한 SQLite 가상 데이터, Linux Chromium에서 확인했다.

이는 Chromium에서 휴대폰 화면을 재현한 결과다. 실제 Android·iPhone·Safari 검증, 운영 NAS 적용 및 적용 후 HTTPS 로그인은 아직 실행하지 않았다. 직원·권한·문서·연차 계산·DB 스키마 및 기존 HTTPS 설정은 변경하지 않았다.

## 이미 설치된 NAS에 적용

[모바일 업데이트 ZIP](../releases/xenosys-mobile-ui-20261016.zip)을 File Station의 `/docker/company-approval`에 올려 **여기에 압축 풀기**를 실행한다. 기존 `app` 폴더를 삭제하거나 전체 교체하지 않는다. 압축 안의 `NAS_MOBILE_UPDATE.txt`에 단계별 안내가 있다.

Windows PowerShell에서:

```powershell
ssh admin@192.168.1.46
```

NAS의 `admin@xenonas:~$`에서:

```sh
sudo sh /volume1/docker/company-approval/xenosys-mobile-ui-20261016/APPLY_MOBILE_UI.sh
```

적용 스크립트는 체크섬을 확인하고 화면 파일 7개를 백업한 뒤 복사한다. 기존 `nas.sh update`가 DB 백업·이미지 빌드·웹 서비스 재시작을 수행한다. 업데이트 동안 접속이 잠시 중단되며 `MOBILE_UI_READY`가 완료 표시다. 오류가 나면 출력과 `.mobile-ui-backup.*` 경로를 보관하고 원인 확인 없이 삭제·재설치·DB 복원을 실행하지 않는다.

휴대폰에서 기존 주소를 새 탭으로 열어 로그인·문서 조회·임시저장·결재를 확인한다. 앱 아이콘은 브라우저의 **홈 화면에 추가** 기능으로 만들 수 있다.

## 개발 환경에서 재현

기존 Django 개발 환경과 Chromium을 사용한다. 검증 도구는 Playwright 1.58.0, 정적 파일 처리는 NAS와 동일한 WhiteNoise 6.9.0으로 확인했다. 운영 DB에 예시 데이터를 넣지 않는다.

```sh
APPROVAL_DATA_DIR=/tmp/approval-mobile-review .venv/bin/python manage.py migrate --noinput
APPROVAL_DATA_DIR=/tmp/approval-mobile-review .venv/bin/python manage.py seed_demo --initial-password mobile-ui-test-only
APPROVAL_DATA_DIR=/tmp/approval-mobile-review .venv/bin/python manage.py shell -c "from workflow.models import Profile; Profile.objects.filter(user__username='admin').update(must_change_password=False)"
APPROVAL_DATA_DIR=/tmp/approval-mobile-review .venv/bin/python manage.py runserver 127.0.0.1:18084 --noreload
```

별도 창에서:

```sh
.venv/bin/python packaging/check_mobile_ui.py
APPROVAL_DATA_DIR=/tmp/approval-mobile-tests .venv/bin/python manage.py test workflow --noinput
python3 packaging/test_mobile_ui_patch.py
python3 packaging/build_mobile_ui_patch.py
```

화면 검증 도구는 localhost/127.0.0.1만 허용하고 가상 계정으로 접속한다. 재현용 가상 DB에는 `seed_demo`의 초기 문서가 필요하다. 적용 시험은 `/tmp`의 가짜 설치에만 실행하고 실제 NAS나 Docker 서비스를 조작하지 않는다.
