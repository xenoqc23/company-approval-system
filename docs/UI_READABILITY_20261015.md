# 넓은 PC 화면 가독성 보완 — 2026-10-15

실제 NAS 첫 로그인에서 브라우저 100%, 가로 2560px 화면의 작은 글씨와 중앙 영역의 여백을 확인했다. 이전 PC 테스트본과 NAS 배포본의 글씨체·CSS는 같았으며 브라우저 축소만으로 설명할 수 없었다. 글씨체는 Pretendard를 유지하고 고정 픽셀 치수를 상대 크기로 바꿔 전체 화면 요소가 함께 조정되도록 했다.

| 화면 가로 너비 | 기본 글씨 | 왼쪽 메뉴 너비 |
| --- | --- | --- |
| 1280~1600px | 기존 14px 유지 | 기존 208px 유지 |
| 1920px | 약 15.17px | 약 225px |
| 2560px 이상 | 17.5px | 260px |

표 제목·설명·입력·버튼·아이콘·카드 간격도 같은 비율로 조정한다. 작은 화면의 반응형 분기와 1px 테두리, 브라우저 배율은 유지한다. 표시 영역의 상한도 같은 비율로 커져 큰 화면에서 중앙 여백을 줄인다. 1366×900의 변경 전후 화면은 픽셀 비교에서 동일했다.

일반 직원·연차/구매 담당자 화면에서 1280·1366·1600·1920·2560px를 포함한 68개 화면/너비 조합의 폰트 로딩·전체 가로 넘침·JavaScript 오류를 점검했다. 운영용 이미지 빌드, 해시 정적 파일, 실제 Gunicorn 로그인 및 2560px 글씨 크기도 확인했다. 직원·결재·연차 계산 코드는 변경하지 않았다.

이미 설치된 NAS에는 releases/xenosys-ui-readability-20261015.zip의 CSS 파일 3개만 app/workflow/static/workflow에 덮어쓴 뒤 nas.sh update로 반영한다. 배포 묶음은 packaging/build_ui_readability_patch.py로 생성하고 원본과 일치를 검증한다. 설치 완료 뒤 화면 크기에 대한 사용자 확인은 별도로 받는다.

운영용 해시 정적 파일을 그대로 사용한 관리자 홈·직원 권한·백업·전체 문서의 1280·1920·2560px 추가 12개 조합도 전체 가로 넘침 없이 표시됐다.
