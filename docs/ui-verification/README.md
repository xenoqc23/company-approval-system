# 민트 플로우 UI·UX 점검

2026-10-15. 가상 데이터가 있는 별도 DB로 실행하여 기존 사용자의 계정과 문서를 변경하지 않았습니다. 구현한 프로그램을 Chromium으로 직접 확인했습니다.

| 항목 | 결과 |
| --- | --- |
| Django 시스템 검사 | 통과 |
| workflow 기능 시험 | 87건 통과 |
| 화면 크기 | 1080 / 1280 / 1366 / 1440 / 1920px |
| 직원·경리·관리자 화면 | 32개 화면 × 5개 너비, 160개 조합 통과 |
| 페이지 전체 가로 넘침 | 점검한 화면에서 없음. 넓은 표는 표 내부에서 스크롤 |
| 낮은 화면의 메뉴 | 직원·권한 관리 및 백업 등 하단 메뉴 접근 확인 |
| 글꼴·일러스트 | 포함된 정적 파일 로딩 확인 |
| 주요 글자 대비 | 선택 메뉴·제목·날짜·상태 등 10개 조합 4.5:1 이상 |

확인한 업무 흐름:

- 홈의 본인 문서 종류 필터, 빈 문서함, 연차 미등록 안내, 상단 알림.
- 구매 기안의 수량×단가 계산, 부서별 결재자 선택, 임시저장, 저장 후 뒤로 이동해도 버튼 재사용 가능.
- 휴가 제출 → 검토 확인 팝업 → 최종 승인 팝업 → 연차 차감 → 최종 승인자 취소 → 차감 복원.
- 경리·관리자 메뉴 표시 및 권한 없는 URL 직접 접근 차단.
- 연차 Excel의 두 시트, 선택 구매 문서 Excel의 선택 행과 가격 표시 `#,##0`.

보완한 배치: 구매/생산 재고 작성의 불필요한 오른쪽 빈 열 제거, 검색 입력창 이중 테두리 제거, 좁은 화면에서 홈 하단 재배치, 낮은 화면의 경리/관리자 하단 메뉴 가림 해결.

이 결과는 Linux의 Chromium에서 확인한 시연 버전입니다. Windows의 setup/run 배치 파일은 기존 실행 방식을 유지했으며 실제 Windows PC, NAS/MariaDB 운영 검증이나 전체 접근성 인증을 의미하지 않습니다.
