실제 브라우저에서 소액 구매 검토 생략·본인 별도 승인·세 단계 구매 검토/최종 승인, 부장 휴가원 최종 차감/취소 복원, 완료 기안의 홈 제외, 규정 시뮬레이터, 연차규정 저장 후 선택 재계산, 경조사비·포상표 편집을 확인했습니다. 공용연차 겹침은 개인 휴가를 자동 취소하지 않았고, 공용연차 삭제 시 실제 차감이 복원되며 입사 전 휴무는 대상에서 제외됐습니다.

기존 세 단계 회귀 시험은 전결 예외를 끈 설정에서 유지하고, 새 전결 시험은 활성 예외 규정에서 별도로 검증합니다. 과거의 완료 문서 선택 허용 시험은 새 요구에 맞게 진행 중 전용 및 0건 안내 시험으로 바꿨습니다.

모든 브라우저 변경 시험은 가상 데이터가 있는 별도 DB를 사용했습니다. 실제 기본 DB 업데이트는 기존 데이터를 비교하여 보존 여부를 확인했습니다. setup/run 실행 도우미는 Linux에서 검증했으며 실제 Windows PC·NAS/MariaDB 동시 운영이나 운영 백업 검증을 의미하지 않습니다.
