# 로컬 PC 알림 테스트 · Chrome / Edge

NAS 업데이트 파일이 아닙니다. 이 폴더를 NAS에 올리거나 실제 결재시스템에 덮어쓰지 않습니다. 실제 계정·문서·DB·NAS 설정을 사용하지 않습니다.

## 시작

1. ZIP을 PC의 새 폴더에 **모두 압축 해제**합니다. ZIP 안에서 바로 실행하지 않습니다.
2. `START_TEST.bat`을 더블클릭합니다. 처음에는 이 폴더 안에 테스트용 `.venv`를 만들고 `pywebpush`를 설치하므로 인터넷 연결과 잠시 기다리는 시간이 필요합니다.
3. 브라우저가 열리면 화면의 1 → 2 → 3 순서로 진행합니다. 주소는 **http://127.0.0.1:18110/** 입니다.
4. 브라우저가 안 열리면 Chrome 또는 Edge 주소창에 위 주소를 직접 붙여넣습니다.

Python이 없으면 [Python 공식 Windows 설치 페이지](https://www.python.org/downloads/windows/)에서 **Python 3.12**를 설치합니다. 설치할 때 **Add python.exe to PATH**를 체크하고 실행 파일을 다시 엽니다. Python 3.10 이상을 지원하며 관리자 권한으로 실행할 필요가 없습니다.

## Chrome 설정

주소창에 `chrome://settings/system`을 붙여넣고 **Chrome 종료 후에도 백그라운드 앱을 계속 실행**을 켭니다.

## Edge 설정

주소창에 `edge://settings/system`을 붙여넣고 **Microsoft Edge가 닫혀 있을 때 백그라운드 확장과 앱을 계속 실행**을 켭니다.

버전에 따라 항목 이름이나 위치가 다르면 설정에서 ‘백그라운드’를 검색합니다. 윈도우 **설정 → 시스템 → 알림**에서 알림을 켜고 **방해 금지**는 끕니다. **Win + N**으로 알림 센터도 확인할 수 있습니다. Chrome과 Edge는 알림 권한과 연결을 각각 설정해야 합니다.

## 테스트 순서

1. **알림 허용하고 연결 → 허용**을 선택합니다.
2. **지금 윈도우 표시 확인**을 눌러 PC가 알림을 표시하는지 확인합니다. 이 버튼은 인터넷 푸시 수신을 시험하는 버튼은 아닙니다.
3. **30초 뒤 결재 요청 알림**을 누르고 먼저 브라우저를 켜 둔 상태에서 확인합니다.
4. 다시 시험할 때는 버튼을 누른 뒤 **해당 브라우저의 모든 창을 닫고** 30초 정도 기다립니다. **검은 실행 창은 계속 켜 둡니다.** 실행 창이 로컬 발송 서버입니다.
5. 다시 테스트 주소를 열면 발송 상태를 볼 수 있습니다. 결재 완료 예시도 같은 방법으로 시험합니다.
6. 다른 브라우저에서도 같은 주소를 열고 별도로 허용·연결해 시험합니다. 테스트를 누른 브라우저에만 발송합니다.

표시하는 직원과 문서는 가상 예시입니다. 서버가 켜져 있으면 브라우저 페이지를 닫아도 30초 후에 서버가 Google 또는 Microsoft의 해당 브라우저 푸시 서비스로 실제 암호화 알림을 보냅니다. 서비스에 전달됐다는 결과는 PC에 표시됐다는 확인과 다릅니다. 실제 표시 여부는 사용 중인 PC에서 직접 확인해야 합니다.

**모든 창 닫기**, **브라우저 프로세스 완전 종료**, **PC 종료**는 서로 다릅니다. 백그라운드 설정을 켜도 브라우저 버전·기업 정책·윈도우 상태에 따라 창을 닫은 뒤 수신이 제한될 수 있습니다. 작업 관리자에서 브라우저 프로세스를 종료했거나 PC가 꺼져 있으면 즉시 수신을 보장하지 않습니다. 창을 켰을 때와 닫았을 때를 비교하는 것이 이 테스트의 목적입니다.

## 안 보이면

- 먼저 ‘지금 윈도우 표시 확인’, 알림 허용, 방해 금지, 알림 센터를 확인합니다.
- ‘결과 확인’에서 **연결 실패 / 발송 실패**라면 인터넷과 회사 보안 프로그램의 푸시 연결 제한을 확인합니다. 보안 기능을 끄지 않고 오류 내용을 확인합니다.
- **푸시 서비스에 전달**인데 PC 팝업이 없으면 브라우저·윈도우 표시 설정을 확인합니다. **창을 열 때만 표시**되면 브라우저 백그라운드 수신 조건을 확인해야 합니다.
- ‘확인 결과 복사’를 눌러 브라우저·권한·연결·발송 결과를 전달할 수 있습니다. 이 결과에는 구독 주소나 암호화 키를 넣지 않습니다.

## 종료와 보관

검은 실행 창에서 **Ctrl+C**로 종료합니다. 이때 대기 중이던 테스트와 메모리의 구독 정보는 사라집니다. 다시 실행하면 기존 브라우저 알림 권한과 구독으로 재연결할 수 있습니다. 완전히 해제하려면 화면의 **이 브라우저 연결 해제**를 누릅니다.

이 폴더 안의 `.local-test-data`에는 테스트용 비밀키, `.venv`에는 실행에 필요한 라이브러리가 보관됩니다. 이 두 폴더를 공유하지 않습니다. 배포 ZIP에는 이 파일들을 포함하지 않습니다. 기존 NAS·결재 프로그램 파일은 변경하지 않습니다.
