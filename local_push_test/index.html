로컬 테스트 v2 · NAS 연결 없음

PC 알림, 먼저 시험해 보세요.

Chrome·Edge 알림과 PC 로그인 시 미결 문서 알림을 확인하는 별도 테스트입니다.
실제 직원 계정이나 결재 문서를 사용하지 않습니다.

출근해서 PC를 켰을 때의 알림은 아래 4번 ‘PC를 켰을 때 미결 문서 알림’에서 시험해 주세요. 날짜가 바뀌지 않아도 미결 문서가 남아 있으면 다시 알려줍니다.

1

브라우저 설정 한 번만 확인

현재 브라우저: 확인 중. Chrome과 Edge는 각각 설정하고 시험해 주세요.

Chrome

주소창에 아래 주소 붙여넣기

chrome://settings/system

Chrome 종료 후에도 백그라운드 앱을 계속 실행 항목을 켜 주세요.

Microsoft Edge

주소창에 아래 주소 붙여넣기

edge://settings/system

Microsoft Edge가 닫혀 있을 때 백그라운드 확장과 앱을 계속 실행 항목을 켜 주세요.

항목 이름은 브라우저 버전에 따라 다를 수 있습니다. 해당 항목이 없으면 설정에서 ‘백그라운드’를 검색해 주세요.

윈도우 설정 → 시스템 → 알림에서 알림을 켜고, 방해 금지는 꺼 주세요. 팝업이 안 보이면 Win + N으로 알림 센터도 확인해 주세요.

이 설정은 창을 닫은 뒤에도 브라우저가 백그라운드에서 동작하도록 돕습니다. 브라우저를 완전히 종료하거나 PC를 끈 상태의 즉시 수신은 보장하지 않습니다.

2

이 브라우저 알림 허용

아래 버튼을 누른 뒤 브라우저가 물으면 허용을 선택해 주세요. 다른 브라우저에서도 따로 허용해야 합니다.

테스트 도구를 준비하고 있습니다.

‘지금 윈도우 표시 확인’은 PC 표시만 확인합니다. 창을 닫은 뒤의 수신은 아래 3번으로 시험해 주세요.

3

30초 후 알림 보내기

원하는 버튼을 누른 뒤 Chrome 또는 Edge의 모든 창을 닫고 30초 정도 기다려 주세요. 첫 시험은 창을 켜 둔 상태로 해도 됩니다.

검은 실행 창은 계속 켜 두세요. 로컬 알림 발송 프로그램이 실행되는 창입니다. 브라우저 창을 닫는 것과 실행 창을 닫는 것은 다릅니다.

결재 요청 예시

개발팀 홍길동 대리님이 휴가원을 올렸습니다. 검토해 주세요.

결재 완료 예시

신청하신 구매요청서의 결재가 완료되었습니다.

이 브라우저를 먼저 연결해 주세요.

두 예시는 가상 내용입니다. 테스트 알림은 30초 간격으로 요청할 수 있으며, 누른 브라우저에만 보냅니다. 알림을 클릭하면 이 테스트 화면으로 돌아옵니다.

4

PC를 켰을 때 미결 문서 알림

PC를 켜고 Windows에 로그인하면 처리할 문서가 남아 있는지 알려줍니다. 이 테스트는 브라우저와 별도로 실행하므로 브라우저·검은 실행 창을 미리 열어 둘 필요가 없습니다.

  1. 가상 미결 2건 만들기를 누릅니다.
  2. PC 켜기 알림 지금 시험으로 먼저 팝업을 확인합니다. 재부팅하지 않고 같은 동작을 시험합니다.
  3. Windows 로그인 자동 알림 켜기를 한 번 누릅니다. 현재 Windows 사용자에게만 시작 프로그램으로 등록됩니다.
  4. 브라우저와 검은 실행 창을 닫고 PC를 재시작해 로그인합니다. 약 15~30초 뒤 오른쪽 아래와 알림 센터(Win + N)를 확인합니다.
  5. 다시 START_TEST.bat을 열어 가상 문서를 처리완료하면, 다음 알림부터 그 문서는 제외됩니다.

미결 문서를 확인하고 있습니다.

이 테스트 폴더를 이동하거나 삭제하면 자동 알림이 실행되지 않을 수 있습니다. 보관할 위치에 압축을 푼 뒤 등록해 주세요. 종료할 때는 ‘자동 알림 끄기’ 또는 폴더의 DISABLE_AUTO_START.bat을 실행합니다.

알림만 봐도 문서는 미결로 남습니다. 날짜나 문서 작성 시점에 관계없이 미결 문서를 확인하며, 미결이 없으면 로그인 팝업을 띄우지 않습니다. Windows 알림에서 ‘사내결재 PC 알림 테스트’를 허용해 주세요. 실제 NAS 문서는 조회하지 않고, 이 PC에 저장한 가상 문서만 사용합니다.

안 보일 때 확인할 순서

  1. 창을 켜 둔 상태에서 ‘지금 윈도우 표시 확인’을 눌러 보세요.
  2. 윈도우 알림 허용, 방해 금지, 알림 센터(Win + N)를 확인해 주세요.
  3. ‘30초 뒤 알림’을 누르고 창을 켜 둔 상태에서 받아 보세요.
  4. 그다음 같은 시험을 모든 브라우저 창을 닫은 상태로 해 보세요.
  5. 테스트 주소를 다시 열어 아래 ‘결과 확인’을 누르면 발송 상태를 볼 수 있습니다.

푸시 서비스에 전달됐다는 결과와 실제 PC에 팝업이 표시됐다는 결과는 다릅니다. PC 표시는 직접 확인해 주세요. 브라우저 알림 권한과 Windows 방해 금지 설정은 자동 변경하지 않습니다. 로그인 자동 실행은 4번에서 직접 켜고 끕니다.

1~3번 웹 푸시 시험은 인터넷과 검은 실행 창이 필요합니다. 4번 로그인 알림은 저장한 가상 문서를 PC에서 확인합니다. 자동 알림은 직접 켜거나 끌 수 있으며, NAS나 실제 결재시스템에는 연결하지 않습니다.
