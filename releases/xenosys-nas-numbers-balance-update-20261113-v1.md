# 문서번호 변경·기안자 연차 표시 · NAS 업데이트

휴가원과 구매요청서에 월별 문서번호를 부여하고, 휴가원 기안자 이름 옆에 잔여·총연차를 표시합니다. 기존 직원 계정·권한·문서·결재선·연차·공지·설치 파일·PC 알림 연결을 유지합니다. 직원 PC 프로그램은 다시 설치하지 않아도 됩니다.

## 문서번호

- 휴가원: `XEN-OFF-2611-0001`
- 구매요청서: `XEN-BUY-2611-0001`
- `2611`은 제출일 기준 2026년 11월입니다. 휴가일이나 임시저장한 날짜를 기준으로 하지 않습니다.
- 휴가원과 구매요청서의 순번은 각각 관리하며 매월 `0001`부터 시작합니다. 12월 첫 휴가원은 `XEN-OFF-2612-0001`입니다. 9999건을 넘으면 다섯 자리로 이어집니다.
- 업데이트 후 처음 제출하는 문서에 새 번호를 부여합니다. 임시저장 중에는 새 번호를 부여하지 않습니다.
- 기존 제출 문서의 `DOC-…`, `PUR-…` 번호와 보고서에 보관된 번호는 그대로 유지합니다. 승인·반려·취소로 문서번호가 바뀌지 않습니다. 생산 재고 요청과 경리의 결제 요청 묶음 번호는 기존 형식을 유지합니다.
- 새 구매번호는 문서 검색과 구매 목록에서도 검색할 수 있습니다. 기존 `PUR-날짜-순번` 전체 번호 검색도 지원합니다.

## 기안자 연차 표시

휴가원 결재 경로의 첫 번째 기안자 카드에서 이름 옆에 **잔여 7일 / 총 15일** 형태로 표시합니다. 기존 문서에도 이 표시를 제공합니다.

표시는 **해당 휴가 사용 연도의 현재 연차**를 기준으로 합니다. 기안 당시의 고정값이 아닙니다. 최종 승인으로 차감되거나 승인 취소로 복원된 값은 문서를 새로 열거나 새로고침하면 반영됩니다. 표시 위에 마우스를 올리면 기준 연도를 확인할 수 있습니다. 연말·연초에 걸친 휴가는 각 연도의 잔여·총연차를 표시합니다.

직접 등록·조정 내역을 포함한 기존 연차 자료를 읽습니다. 표시 기능은 연차를 새로 산정하거나 차감하지 않습니다. 연차가 등록되지 않은 연도는 **연차 미등록**으로 표시합니다. 0일·소수점·음수 잔여도 실제 값으로 표시합니다. 문서를 열 수 있는 직원에게만 보이며 구매요청서와 생산 재고 카드에는 연차를 표시하지 않습니다.

기존 검토·승인자 의견과 직원 이름 검색 기능도 포함합니다. 이 업데이트가 설치 안내 공지를 다시 등록하거나 본문을 덮어쓰지는 않습니다.

## NAS 적용

1. `xenosys-nas-numbers-balance-update-20261113-v1.zip`을 File Station의 **docker → company-approval → updates**에 올립니다.
2. **현재 폴더에 압축 풀기**로 새 `xenosys-nas-numbers-balance-update-20261113-v1` 폴더를 만듭니다.
3. Windows PowerShell에서 NAS에 접속합니다.

```sh
ssh admin@192.168.1.46
```

4. `admin@xenonas` 프롬프트에서 사전점검을 실행합니다.

```sh
sudo sh /volume1/docker/company-approval/updates/xenosys-nas-numbers-balance-update-20261113-v1/UPDATE_NAS.sh precheck --operator admin
```

5. `Precheck complete`를 확인한 뒤 업데이트를 실행합니다.

```sh
sudo sh /volume1/docker/company-approval/updates/xenosys-nas-numbers-balance-update-20261113-v1/UPDATE_NAS.sh update --operator admin
```

사전점검이 실패하면 업데이트를 진행하지 않습니다. 기존 담당자 옵션을 별도로 사용했다면 사전점검과 업데이트에 동일하게 지정합니다. 업데이트 중 웹 서비스가 잠시 중지되며 백업·마이그레이션·기존 데이터와 첨부 보존 검사를 수행합니다. `Update complete` 후 홈페이지를 새로고침합니다.

## 확인

- 기존 문서와 보고서의 번호가 그대로인지 확인합니다.
- 새 휴가원과 구매요청서를 각각 제출해 새 번호 형식을 확인합니다. 임시저장 후 제출한 문서도 제출한 월의 번호를 사용합니다.
- 휴가원에서 기안자 옆 연차가 해당 직원의 연차 관리 값과 일치하는지 확인합니다. 승인 시 차감·취소 시 복원되는 기존 동작을 유지합니다.
- 검토·승인자 의견, 직원 연차 이름 검색, 기존 공지 첨부와 PC 알림 연결이 유지되는지 확인합니다.

실제 NAS에는 자동 적용하지 않습니다. 개발 검증은 가상 계정과 별도 DB에서 수행합니다.

## 복구

이전 이미지와 업데이트 전 백업을 보관합니다. 복구가 필요하면 오류를 확인한 뒤 다음 명령을 사용합니다. 업데이트 후 새로 제출한 문서가 있다면 되돌릴 시점을 먼저 확인합니다.

```sh
sudo sh /volume1/docker/company-approval/updates/xenosys-nas-numbers-balance-update-20261113-v1/UPDATE_NAS.sh rollback
```
