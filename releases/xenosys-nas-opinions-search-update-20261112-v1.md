# 직원 이름 검색·검토 및 승인 의견 · NAS 업데이트

직원별 연차 관리 화면에 직원 이름 검색을 추가하고 휴가원·구매요청서의 검토·승인 의견을 기록합니다. 이미 제출한 대기 문서에도 적용됩니다. 기존 계정·암호·직원 권한·결재선·문서·연차·공용연차·공지·첨부·PC 알림 계정 연결을 유지합니다. 직원 PC 프로그램은 다시 설치하지 않아도 됩니다.

## 변경 내용

직원별 연차 관리에서 **직원 이름**에 전체 이름 또는 일부를 입력하고 **검색**을 누릅니다. 선택한 부서·연도와 함께 적용됩니다. **검색 해제**는 이름 검색만 해제합니다. 수정 후에도 검색 조건을 유지하며, 엑셀 다운로드도 같은 직원만 내보냅니다. 이름 검색은 연차 관리 권한이 있는 계정에만 제공하고 일반 직원은 본인 연차만 조회합니다. 검색은 연차 수치를 바꾸지 않습니다.

문서 오른쪽에 **검토자 의견 · 선택** 또는 **승인자 의견 · 선택** 입력칸이 표시됩니다. 최대 1000자이며 비워도 검토·승인할 수 있습니다. 입력한 의견은 검토 완료·승인자에게 전달·승인완료·허용된 검토자 전결을 실제 처리할 때 함께 저장합니다. 승인 취소·반려·담당자 변경의 사유는 별도로 유지합니다. 기존에 입력한 메모는 기존 변경 이력에서 계속 확인할 수 있습니다.

신청 내용 아래 **검토·승인자 의견** 영역에 작성 당시 이름·직급·처리 단계·시간과 의견을 표시합니다. 의견의 수정·삭제 기능은 제공하지 않습니다. 승인 취소 후에도 당시 의견은 보존합니다. 문서를 볼 수 있는 직원만 의견을 볼 수 있고, 현재 단계의 담당자만 의견과 검토·승인을 함께 처리할 수 있습니다. 기존 문서에는 새로운 의견을 임의로 생성하지 않습니다. 생산 재고의 확인 완료에도 의견을 남길 수 있으며 경리에게 문서를 보내지 않는 기록용 흐름은 유지합니다.

기존 설치 안내 공지와 파일은 유지하며 공지를 다시 등록하거나 본문을 덮어쓰지 않습니다. PC 알림 프로그램의 설치·동작은 변경하지 않습니다.

## NAS 적용 순서

1. `xenosys-nas-opinions-search-update-20261112-v1.zip`을 File Station의 **docker → company-approval → updates**에 업로드합니다.
2. ZIP에서 **현재 폴더에 압축 풀기**를 선택합니다. 새 폴더가 `xenosys-nas-opinions-search-update-20261112-v1`인지 확인합니다.
3. Windows PowerShell에서 NAS에 연결합니다.

```sh
ssh admin@192.168.1.46
```

4. `admin@xenonas` 프롬프트에서 사전점검을 실행합니다.

```sh
sudo sh /volume1/docker/company-approval/updates/xenosys-nas-opinions-search-update-20261112-v1/UPDATE_NAS.sh precheck --operator admin
```

5. `Precheck complete`를 확인한 뒤 실제 업데이트를 실행합니다.

```sh
sudo sh /volume1/docker/company-approval/updates/xenosys-nas-opinions-search-update-20261112-v1/UPDATE_NAS.sh update --operator admin
```

사전점검이 실패하면 업데이트를 진행하지 않습니다. 기존 역할 옵션을 별도로 지정했다면 사전점검과 업데이트에 동일한 옵션을 사용합니다. 업데이트 중 웹 서비스가 잠시 중지됩니다. 백업·마이그레이션·기존 데이터와 첨부 보존 검사를 마친 후 서비스를 재시작합니다. `Update complete` 후 브라우저를 새로고침합니다.

## 적용 후 확인

- 직원 이름을 검색하고 부서·연도를 변경해 검색 조건이 유지되는지 확인합니다. 엑셀에 검색한 직원만 있는지 확인합니다.
- 검토자·승인자 계정으로 대기 문서를 열어 의견 입력칸과 기존 처리 버튼을 확인합니다. 의견을 비워도 처리할 수 있습니다.
- 의견을 작성한 뒤 실제 검토·승인을 완료하면 신청 내용 아래에 표시됩니다. 의견을 쓰는 것만으로 저장되거나 문서가 승인되지는 않습니다.
- 검토자 전결 버튼은 기존 직원·권한 관리에서 허용한 직원에게만 표시됩니다.
- 이전 설치 안내 공지와 설치 파일 다운로드, 기존 PC 알림 연결이 유지되는지 확인합니다.

개발 검증은 별도 DB와 가상 계정으로 수행하며 실제 NAS에 자동 적용하지 않습니다.

## 복구

업데이트 스크립트가 이전 이미지와 백업을 보관합니다. 업데이트가 실패하면 오류를 먼저 확인하고 필요 시 다음 명령으로 복구합니다. 업데이트 후 새로 쓴 의견이나 문서가 있다면 되돌릴 백업 시점을 먼저 확인합니다.

```sh
sudo sh /volume1/docker/company-approval/updates/xenosys-nas-opinions-search-update-20261112-v1/UPDATE_NAS.sh rollback
```
