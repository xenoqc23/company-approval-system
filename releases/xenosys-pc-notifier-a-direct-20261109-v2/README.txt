XENOSYS PC 알림 · 압축 해제 없는 설치 파일

직원: XenosysApprovalSetup.exe를 실행하고 이 PC에 설치 → 본인 계정 연결을 진행합니다.
브라우저에서 같은 확인 코드를 확인하고 이 계정으로 PC 연결을 누릅니다.
Windows 로그인 시 자동 실행을 켜 둡니다. 홈페이지 로그인과 PC 프로그램 계정 연결은 별도로 유지됩니다.

관리자: 공지사항의 설치 안내 표시를 켜고 이 EXE 파일을 첨부하면 공지의 다운로드 버튼으로 제공합니다.
다운로드 버튼만으로 자동 실행되지 않으며 직원이 받은 파일을 실행해야 설치됩니다.
기존 설치자는 같은 알림 기능을 계속 사용할 수 있으므로 다시 설치하지 않아도 됩니다.
설치 파일의 오픈소스 라이선스 링크와 프로그램의 작업표시줄 메뉴에서 런타임 고지를 확인할 수 있습니다.

Windows 10 22H2 / Windows 11 64비트용입니다. Python과 .NET을 따로 설치하지 않습니다.
로컬 서버 연결·빌드 검증은 수행했습니다. 이 압축 배포 EXE의 실제 Windows 설치·보안 제품 판정은 별도 확인 대상입니다.
